# G2.1：监督机会识别诊断与有限训练结果

本轮完成了预注册的离线阶段：固定16状态检查、只改采样的配对对照、条件触发的收益监督配对对照。共5个训练过程、8,704次优化器更新；新增环境查询0，新增PPO动作0。没有扩大场景，没有改动冻结G2，部署仍使用Fixed3／Detour。

训练于2026-11-03执行，交付检查于2026-11-04完成。本轮新增G21纯张量／合成数据／mock测试73/73通过。冻结核对中，本地对应原包的2617/2617文件匹配，相关旧版压缩包哈希一致。实际增量ZIP的新目录复验另见同级外部回执 `rc3_rl_g21_delivery.smoke.json`，它不改变训练结果。

结论：现有图网络能拟合小集合；提高根状态采样权重改善了训练初始状态上的识别，但不足以通过开发门槛。当前收益差辅助损失提高部分机会检出，同时降低STOP选择并增加未知动作选择。所有最终模型均未达到进入PPO的条件。本轮没有获得可替换默认规划器的学习模型，也没有测出新的路径质量或规划耗时优势。

## 1. 16状态检查通过

8个正状态、8个STOP明确占优状态按原case顺序和预先固定的margin选择，未根据模型表现挑选。

| 最终512更新指标 | 实测 | 预注册门槛 |
| --- | --- | --- |
| 已查询集合内near-best命中 | 16/16 | ≥15/16 |
| 正状态选择已知正收益继续动作 | 8/8 | ≥7/8 |
| 完整合法集合中的已知正继续 | 7/8 | 仅诊断 |
| 完整合法集合中的near-best命中 | 10/16 | 仅诊断 |
| 完整合法集合中的未知动作选择 | 6/16 | 仅诊断 |
| 8个STOP占优根的完整动作STOP选择 | 3/8 | 仅诊断 |

完整动作中有1个正状态及5个STOP占优状态选择未查询动作，其质量未知。该结果支持“此模型和优化过程可拟合此16状态的已查询标签”，不能推出完整动作选择、64根或新场景有效。后续实验都重新从冻结初始BC出发，没有复用这个记忆模型。

## 2. 根权重修正有局部改善

两组训练都使用初始64场景的512个已有教师状态，网络、标签、优化器初态和2048更新预算一致。唯一实验因素为采样分布。

| 初始64根上的最终指标 | 原采样 | 根占半采样 |
| --- | ---: | ---: |
| 实际根曝光／总曝光 | 3,876/65,536 | 32,753/65,536 |
| 已查询near-best命中 | 33/64 | 40/64 |
| 已查询集合内正机会检出 | 15/39 | 21/39 |
| 完整合法集合已知正机会检出 | 10/39 | 15/39 |
| 25个已查询STOP占优根中的STOP选择 | 20/25 | 21/25 |
| 完整合法集合未知动作选择 | 16/64 | 14/64 |
| 根已查询Q regret均值 | 0.25510 | 0.21706 |
| 后继已查询near-best命中 | 297/448 | 309/448 |
| 后继已查询Q regret均值 | 0.13417 | 0.12333 |
| 旧extra32的26正根，完整动作已知正检出 | 4/26 | 4/26 |

这是当前单种子和预算下的受控改善，不能证明低根权重是G2失败的唯一或主要原因。旧extra32没有相应改善；它本来就曾用于G2开发，不能当作全新确认性测试。

## 3. 当前收益辅助项产生了明显取舍

为区分“多训练”与“收益监督”，两组从同一个root50最终权重重启相同Adam、使用相同采样序列，各追加2048更新。辅助项为已查询非STOP动作的 `SmoothL1(logit(a)-logit(STOP), Q_T(a)-Q_T(STOP))`，系数1；仅用于教师深度2的根状态。后继深度1不参与回归，未知动作不被补零或标坏。critic头未进行监督训练。

| 初始64根上的最终指标 | 再训练CE | CE＋收益辅助 |
| --- | ---: | ---: |
| 已查询near-best命中 | 51/64 | 43/64 |
| 已查询集合内正机会检出 | 29/39 | 35/39 |
| 完整合法集合已知正机会检出 | 22/39 | 25/39 |
| 25个已查询STOP占优根中的已查询STOP选择 | 24/25 | 11/25 |
| 上述25根的完整动作STOP选择 | 21/25 | 2/25 |
| 完整合法集合未知动作选择 | 12/64 | 29/64 |
| 根已查询Q regret均值 | 0.08382 | 0.07598 |
| 后继已查询near-best命中 | 342/448 | 332/448 |
| 后继已查询Q regret均值 | 0.07823 | 0.08942 |
| 旧extra32的26正根，完整动作已知正检出 | 5/26 | 12/26 |

这里出现“regret均值略低，但near-best及停止准确性更差”的取舍；单个平均数不足以决定部署。收益辅助模型在25个已查询STOP占优根中，有19个选择未知动作；不能将这19个都算成已证明负收益的错误。但在只保留已查询动作时也仅11/25选STOP，说明问题不完全由未知动作导致。

该结果仅否定本次具体损失组合已经完成修复，不能推出所有收益监督或分层停止设计均无效。系数1、用actor logit差表示收益、有限训练预算都有待单独验证。

## 4. 为什么没有进入PPO

进入新交互的四项预注册开发阈值是：初始正机会检出≥70%；旧extra正机会检出≥50%；初始STOP占优根的完整动作STOP率≥75%；初始根未知选择≤20%。要求同时满足。

| 最终候选 | 初始正机会 | extra正机会 | STOP选择 | 未知选择 | 通过 |
| --- | ---: | ---: | ---: | ---: | --- |
| 原采样 | 25.64% | 15.38% | 80% | 25% | 否 |
| 根占半 | 38.46% | 15.38% | 84% | 21.88% | 否 |
| 再训练CE | 56.41% | 19.23% | 84% | 18.75% | 否 |
| CE＋收益 | 64.10% | 46.15% | 8% | 45.31% | 否 |

门槛是运行前固定的工程决策标准，不是统计显著性标准。即使中间更新出现较高的某项检出率，也没有据此挑选模型、更改阈值或启动PPO。`outputs/decision.json`明确记录暂停在离线阶段，PPO授权文件未生成。

## 5. 模型与后续接口

5份模型保存于 `outputs/<run>/model.pt`，带协议、训练代码、父权重和源码哈希；对应日志、逐状态动作和诊断齐全。toy仅用于可学习性检查；其余4份用于研究对照，都未推荐部署。

新预备代码包含：可合理早停的Detour、最多一次真实提案的学习控制、独立G21评估入口，以及≤4096动作PPO骨架和原始STOP/continue优势、critic误差/解释方差、提案计数、同场景STOP解析参照日志。它们仅通过纯张量、合成数据或mock测试，尚未验证多进程场景端到端行为；不将“代码准备”计成训练或算法效果。未来PPO仍需冻结早停参数并完成一步控制的场景集成。

下一项研究应先分开诊断停止判断与已查询动作排序，以及已查询／未查询动作的分数尺度。可将共享编码器下的分层stop/continue头作为下一轮受控候选，但需要新的预注册和匹配CE对照。本轮没有额外开展结构搜索、增加查询或继续堆更新。
