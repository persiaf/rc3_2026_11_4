# v3 的开源依据、改动边界与训练方案

核查日期：2026-11-02。这里区分官方代码做了什么、本项目借鉴什么以及尚未证明什么。上传报告中的建议作为待核查意见；本轮执行依据是用户要求继续优化、训练并验证快速规划模型。

## 为什么本轮先采用多状态收益监督

v3 把学习目标改为：从较强的 Fixed3 初解出发，在当前路线和剩余预算下选择值得执行的局部覆盖修复，或者停止。仅在初始路线采集标签，不能覆盖多次修复后的路线分布；只保留正收益样本，又无法教会模型判断“此时无需再花搜索预算”。因此本轮采集真实中间状态，并保留穷举当前合法窗口后得到的全零收益状态。

这是**监督式局部收益预测与排序**，不是 PPO。本轮的多步环境不自动使离线监督训练变成强化学习；oracle、detour、random 混合轨迹也不是 DAgger，因为当前数据生成没有使用学习器在线访问状态再重标注。只有后续实际实现并运行策略采样、奖励、优势估计和策略更新，才能把相应阶段单独报告为强化学习。

## 数据、目标与训练实现

`data.py` 从规范化后的 Fixed3 三种候选 `(0,1,7)` 中选成本最低路线作为参考。每个训练场景按编号轮转选择 oracle、detour 或 random，执行最多 8 次真实修复。偶数场景保留步 0/2/4/6，奇数场景保留 1/3/5/7；提前没有合法窗口时记录真实终止，不补造状态。为了采集后期的零收益状态，oracle 在所有窗口收益为零时仍可尝试剩余动作；这是数据采样机制，部署 oracle 应停止。

每个保存状态对**全部当前合法窗口**调用同一修复器，规范化候选路线后计算标签：

\[
g(s,a)=100\,\frac{\max(0,J(\pi_s)-J(\operatorname{canonical}(\operatorname{repair}(\pi_s,a))))}{\max(J(\pi_{\mathrm{Fixed3}}),10^{-8})}.
\]

标签单位是相对初始 Fixed3 目标的百分数。标签不得成为推理特征。为避免外部覆盖变化造成旧收益失效，教师缓存以完整规范化路线及窗口位置为键，每个场景独立缓存。报告实际 DP 调用次数、缓存命中、生成时间、正/零状态数及步数分布；其中 DP 时间统计包含修复、规范化和目标计算，不是内层 DP 的纯耗时。

28 维观测包括原有局部路线/覆盖/候选/导航距离特征，加剩余预算、已用步数、当前与参考成本比、累计收益比例。动作窗口 stride 为 1，宽度最多 4；若超过 8 个必要任务或 80 个候选则缩小。约束仍由可达性矩阵与确定性修复器实现，学习器不模拟关节运动。

`model.py` 比较两层、四头、64 维的注意力网络和同维度 MLP；都预测窗口排序、收益、是否正收益，并有独立 STOP 输出。正式 `train.py` 对两种架构使用相同损失：正收益状态的收益平方根归一化排序目标、全部状态的收益回归和正收益分类，以及无类别加权的全局“无正收益”STOP二分类。STOP与窗口分布分开，以固定0.9阈值保守停止；这不是校准正确率保证。首轮把STOP放入窗口softmax的实现造成提前停止，验证诊断和旧源码保留，未用于最终测试。padding/已尝试动作在注意力、池化与损失中屏蔽。只用训练数据估计标准化参数和正收益分类权重；按验证集真实多步执行后的成本下降选择检查点，同收益时优先少调用修复器。

最终模型可导出 NPZ，以 NumPy 推理降低部署依赖。必须检查重载前后动作和路线成本一致；不能仅凭文件存在认定模型可以正确部署。以上是代码设计说明，实际训练轮数、检查点及结果以训练和评测产物为准。

## 冻结的验证范围与判断标准

- 新训练 96 场景、验证 18 场景，均为 100 桌；regular/mixed/blocked 各模式均衡。默认每场景保存 4 个状态，若真实提前终止则数量相应减少。
- 冻结测试清单包含 54 个主/OOD 场景：12/36/64/100/144/196 桌 × 3 模式 × 3 例；另有 256/400 桌 × 3 模式 × 1 例，共 6 个压力测试，单独报告。更大规模保持物理尺寸，不将桌子或机器人等比缩小。
- 测试生成阶段仅保存 seed/规模/模式元数据，不构造测试场景或读取测试成本。seed 排除可读取的历史 JSON/JSONL/CSV 元数据和旧计划文件名；损坏历史文件在审计中列明，不能宣称已排除其不可读内容。
- 主要对照必须从相同 Fixed3 开始，使用同一窗口和修复器，比较随机、detour、注意力、MLP 的固定修复调用预算与完整时间预算。仅优于更弱初解不足以证明选择器有效。
- 相对 Fixed3 的收益来自“修复器＋选择策略”；学习的额外价值应通过同预算的 random/detour 对照识别。注意力未必优于 MLP，应按验证选择并完整报告两者。
- 若要增加 RL 或继续调参，应保持新的最终测试未使用；不能根据已查看的测试成本反复选模型。训练损失下降、任务完成率高或规模能跑通，都不能替代路线质量与端到端时延的证据。

真实机械臂可达性、动态任务到达、搬运容量和非完整底盘约束不在本轮验证范围。模型输出可靠性依靠已验证初解、候选检查和成本不增替换；该保证是对当前二维代理模型而言，不是物理机器人执行认证。
