# 正式训练器实施评审

本轮采用新206维训练入口；旧202维训练循环不调用。准确SL256导出和S1/update0256、sidecar、commit收据均核SHA。旧Actor仅提供冻结202维特征，旧残差头删除；新206维修正独立初始化，末层为零。全基座eval、requires_grad=False，train切换和每次更新前后都核冻结张量。

环境保持正覆盖增益mask、same-arm F&A、完整任务覆盖、显式入口/出口及独立二维代理验证器。全局任务ID、候选ID与导航节点ID分别记录；假设服务先扣C覆盖任务，再对剩余任务使用全部可服务provider的绕障D。不可达量独立保留，不删例、不重采样。每个请求重新准备来源绑定的provider表，不跨请求复用动态状态。

Critic独立预测raw剩余L/K和有符号H信用；价值为-(L+.75K-H)/固定初始任务数。完整gamma=lambda=1回报扣原冻结H后的完整J；H信用不是物理剩余距离。Actor只使用冻结V_old形成G-V_old，修正Adam与Critic Adam分开。候选更新前深拷贝修正参数和Adam，使用同mask、逐状态最大KL/概率变化及相对基座TV核guard；拒绝精确回滚，实际调用不退款，不改阈值或学习率。

新入口按一次机会=一次Actor候选+一次Critic步计数。匹配继续监督采用相同206维OFF修正、初始参数、Adam和guard，在原256标签池上做route-mean CE；输入来源和接受次数可不同，不能声称FLOPs匹配。所有真实更新前持久扣账。

Checkpoint包含修正/Critic/两Adam、Python/NumPy/Torch RNG、已用轨迹、游标、源码/协议/H/种子/环境与完整持久账本前缀。只允许闭合边界恢复；脏请求/优化器事务保留并拒绝重放。部署包仅含修正权重和准确冻结基座引用，严格新schema加载，不含Critic或Adam。

物理身份：96个训练父布局；评价48个selection视图来自其中8个父布局，18个既有开发视图来自另外3个父布局。均为已暴露开发数据，非新保留测试。实际输入只从哈希绑定的保存文件加载；不调用旧Inputs的生成分支，不修改旧INDEX。
