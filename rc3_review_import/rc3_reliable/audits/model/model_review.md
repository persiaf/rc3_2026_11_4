# 当前实验的模型边界与条件性保证

## 结论

当前最可用的对象是“静态通道图与固定高度操作空间代理约束下的覆盖路由求解器”，不是实机双臂协调控制器，也不是已经证实具有跨规模优势的端到端学习规划器。Fixed1 适合低开销，Fixed3 适合增加候选预算后的质量改善。随机森林仅选择有限启发式配方，没有改变共同可行约束；其额外收益应由同预算固定组合对照确认。

## 证据复验

- 当前 fast 基准的 baseline.py SHA-256 与基准 manifest 完全一致。
- 按每种规模与场景模式的文件名字典序首例固定抽样，重验 IID 四尺度三模式与 OOD 两尺度三模式，共 18 场景、162 方案；全部通过当前 validator，全部任务完成，零碰撞。
- 旧 attention 最终实验全部 72 份保存方案经当前 validator 重验通过。学习源码哈希与旧 run_manifest 全部一致；baseline.py 与 validator.py 已变化。旧方案仍满足当前模型校验，不等于已证明代码逐字节重放或旧耗时可复现。
- 以上重验没有重新训练、推理或优化路线，没有改写任何历史性能指标。

## 三层覆盖指标

令 C_ij 表示球壳与水平扇形代理可行，V0 为通道图中与 depot 双向连通的候选集合。

1. 几何候选可服务：A_i = 1[存在 j，C_ij=1]。
2. 导航与操作联合可服务：B_i = 1[存在 j 属于 V0，C_ij=1]。
3. 规划完成：D_i = 1[最终已认证服务记录中恰有一条合法分配对应任务 i]。

完整有效计划应分别报告 sum(A)/N、sum(B)/N、sum(D)/N。当前 baseline 的 feasible_tasks 是第一层，不能把它读成导航与操作联合可行。valid_model_plan 仅表示已输出部分没有违反声明模型；必须同时检查 all_tasks_served。

baseline 对不可覆盖任务返回 partial，并保留 ID 和失败类别；fast 在构造时遇到剩余任务无可达候选会抛出 ValueError。新适配层将此变成结构化 no_service_candidate/disconnected 失败，不误报物理世界无解。

## 条件性完备性

假设有限、静态、无向非负权导航图；每项任务至少有一个 V0 内候选；任务独立且没有容量、时窗、同步、共享资源或先后约束。每次只选择对未完成任务有正新增覆盖的候选，因此剩余任务数量严格下降，最多 N 次构造动作完成全部任务，并且能够返回 depot。

该保证依赖候选完备性和约束，不依赖是否使用学习。当前实验中100%完成率首先是可行性门槛，不应归功于神经网络。

## 局部搜索的覆盖与成本保证

- 2-opt 不改变服务点集合。对称最短路成本矩阵下，内部反向边成本抵消，接受的交换降低导航成本。
- 替换某停靠时，新候选必须覆盖旧停靠独占的全部任务；其他任务至少还由另一停靠覆盖。仅在前后连接的总距离降低时替换，因此覆盖不丢失且固定停靠数下目标不增。
- 删除无独占覆盖的冗余停靠不影响覆盖。导航成本满足最短路三角不等式，删除中间停靠的直接连接不比经该点更长；非负停靠惩罚也不会增加。
- 最终按访问顺序重放覆盖，删除零新增覆盖停靠，同样保持任务覆盖并不增加该度量上的目标。

因此 default_joint 可以相对其相同 coverage 初解提供单调改进。Fixed1 或 learned 配方从另一个初解开始，不自动不劣于旧 coverage；top-k 只保证不劣于自己实际计算过的候选集合。

## 可认证锚点

新独立适配层位于 deliverables/rc3_reliable。默认锚点 Fixed1=[1]，质量模式追加0、7；每个候选必须完整导出与重验后才可替换 incumbent。因此返回 J <= J_fixed1，只针对同一场景、同一候选/通道图和同一目标。

可选 reference=legacy 使用本上传 Python coverage_cost_2opt 作为认证锚点，再尝试default_joint及固定组合，可以给出对该 legacy 的成本兜底；不是对论文其他 MATLAB 场景的自动比较保证。候选失败保留旧 incumbent。max_recipes 只限制候选尝试次数，不是硬实时上限。

## 物理与环境模型边界

当前 F 的竖直项是 task.z - robot.shoulder_height，candidate.h 完全没有参与。任务与肩部高度在常规生成场景中均为0.75m，h=0.40m只是元数据；几何扰动场景不改变任务高度。当前不能声称已完成升降优化或高低桌泛化。新适配层拒绝变化h元数据，避免静默误用。

两个手臂是两组肩部偏置的球壳/扇区，取其并集给独立任务择臂；没有机械臂全姿态、关节极限、碰撞、轨迹连续性或同步干涉检查。模型可靠性不能跨越到真实IK与硬件执行层。

mixed 对桌尺寸、位置、任务和候选作一致的已知几何变换；导航也使用更新后的真实矩形。它检验不同已知场景下的算法表现，不是规划地图与真实场景不一致的定位/标定误差鲁棒性。

blocked 障碍在规划之前加入，导航删除碰撞边，验证器再次检查全部矩形障碍。该场景合法地检验静态结构化通道堵塞，而非执行中的动态避障或在线计划修复。阻塞位置选择在交替横向通道，保留纵向绕行结构，不能外推为任意拥堵地图。

## 推荐展示

研究一展示左右臂/联合可达图及三个覆盖层次；研究二展示分层初解的候选、覆盖关系和停靠序列；研究三在同一场景展示初解、删除/替换后的停靠与路线，再给覆盖保持、成本下降、规划/预处理分项时间及规模曲线。学习与固定组合用同预算配对结果单列，置信区间跨零时明确额外学习收益未证实。动态规划、升降优化、真实双臂协作单列为尚未验证内容。
