# 第四版研究发现与路由

2026-11-03；result-to-claim 总结为 **partial**。完整审阅在 `claims_review.md`，独立复算在 `paper/review-traces/experiment-result-to-claim/2026-11-03_run02/`。

1. **已确认的成果**：39 个新场景、357 组方法记录、855 份方案全部独立检查通过；225 份小规模方案通过。离散模型的初解认证、成本不增和终验回退成立。小规模 45 个场景—罚金组合中44个获全局最优，1个超限明确保留可行解；主26例的Fixed3/Detour平均最优间隙为0.43248%/0.09778%。
2. **学习的正结果**：新百桌18例固定8调用下，结构组相对Detour平均降本0.76987%，95%场景区间[0.45092%,1.08422%]；三个训练种子均有相对Detour质量优势。应保留这个有限结论。
3. **未通过的采用主张**：结构组相对同网络控制组为0.26513%，区间[−0.10053%,0.62231%]；完整规划中位时间为Detour的1.555倍，超过1.25门槛。同400ms软预算相对Detour也未显示优势。因此默认继续Fixed3/Detour，不提升结构模型为默认。
4. **不能继续采用的解释**：输入图并非充分状态；STOP没有在百桌诊断中学到有效停止；80轮训练并不意味着最后一轮最好。不能再只用“轮数不足”解释差距，也不能把全部相对Detour的收益归给结构输入，因为控制组本身也有收益。
5. **真实约束接入状态**：已有AlohaMini1模型身份、固定提交和部分参数定义；缺已核验本地资产、有效限位、TCP/夹爪及升降配置。外部双表接口与合成测试已经完成，真实IK、连续碰撞及实机执行尚未完成。
