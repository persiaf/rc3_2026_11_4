## 0. 老师首先需要知道的结论

研究内容三的目标固定为：在大规模复杂多任务场景中训练深度强化学习模型；模型冻结后，在训练大场景内不同规模的局部任务窗口中，不重新训练即可快速生成满足任务覆盖、底盘通行、左右臂操作可达和安全约束的完整任务路径。[S01]

当前工程已经能够产生代理约束下合法的完整路线，也已经完成多轮真实强化学习训练。但是，现有学习配置尚未稳定优于共同监督起点、继续监督对照和 Fixed3／Detour16 强规则；GL-v5 的冻结贪心参考基线试验亦未通过。轻量策略包的工程提速已经得到局部配对试验支持，不应误称强化学习质量提升。[S06–S08]

希望老师辅助解决的是“怎样使 DRL 训练真正提高自主路径构造能力，并保持冻结模型快速推理”，不是重做底盘低层控制，不是把第三部分替换为动态重规划、纯监督学习或传统规则。算法可以由老师评审调整，研究目标不能改变。

本包提供：详细需求与验收口径；原覆盖论文到当前任务的映射；旧 RC3 可运行源码快照；新的独立接口示例、单元测试、MATLAB 导出模板；当前最新源码的固定版本获取入口。它不是已训练成功的新算法交付。

## 3. 场景、机器人及任务范围

### 3.1 任务场景

典型父场景为 10×10 张桌，桌上随机出现 0–3 个任务。当前阶段按每次任务 episode 开始时给定任务集合理解，不能自行把“随机出现”扩展为执行中的动态新任务流。mixed／blocked 为现有复杂布局类别，regular 仅可作为工程示例。[S01、S05]

局部任务窗口包含指定桌子上的目标任务。机器人仍在完整父地图内运动，允许经过窗口外通道，允许使用窗口外但能够服务目标任务的合法停靠候选。应分别报告“已训练布局上的新任务”和“未训练物理布局上的任务”；前者是主要应用，不应写成未见环境泛化。

### 3.2 机器人抽象及边界

机器人为全向移动底盘、可升降机构与双机械臂。现有二维实验通过离散候选位姿和代理 F/A 表示操作约束，典型实验的升降高度固定。把 h 写入候选不等于已经建立升降过程碰撞或能耗模型；若拟联合优化多个高度，必须另行给出转换代价与验证。[S05、S09]

当前任务按独立串行单臂服务处理：一个任务在选定停靠点由左臂或右臂完成。两臂同时搬运、同步运动、双臂互碰、接触力、夹爪抓取稳定性与关节轨迹，不属于现有代理认证。历史导出器对两臂都可服务的任务优先选择 L，否则 R；这只是合法分配，并非学习得到的负载均衡。[S09]

### 3.3 本阶段明确不做

不把动态重规划作为第三部分替代目标；不训练底盘速度控制或机械臂关节控制；不以相机视野覆盖或“访问桌子”代替完成具体操作任务；不降低安全间隙以通过不可行案例；不把规则回退的成功记为纯神经策略成功。

“轨迹”在本阶段交付中明确指完整空间路径／停靠执行序列。若要求带时间戳、速度／加速度和可执行姿态变化的轨迹，必须另加时间参数化与控制验证模块；当前 polyline 本身不能证明这些动力学约束。

## 4. 数学模型与变量规范

### 4.1 基本数据

设目标任务集合为 T，候选停靠集合为 V，左右臂集合为 {L,R}。候选包含 (x,y,theta,h)，长度单位 m、角度 rad、时间 s。全局 task/table/candidate ID 均为从 0 开始的连续整数；原导航服务节点 0 为基地，候选 j 对应节点 j+1。

F(i,j,a)∈{0,1}：任务 i 在候选 j 是否满足臂 a 的给定操作可达约束。A(i,j,a)∈{0,1}：外部附加允许关系。二者必须在同一只臂上相交。

C(i,j) = OR_a [ F(i,j,a) AND A(i,j,a) ]。

不能错误实现为 [OR_a F(i,j,a)] AND [OR_a A(i,j,a)]；后一写法可能把左臂可达和右臂许可交叉拼成假合法。

D(u,v) 为完整父地图中的安全导航长度，包含基地和全部候选。不可达为正无穷；禁止 NaN、负值和负无穷。当前源模型使用无向导航。D 必须有路径重建证据，不能把直线距离冒充绕障路径。

### 4.2 局部任务可行性

设入口为 e、出口为 x。连通候选满足 D(e,j+1)<∞ 且 D(j+1,x)<∞。当前窗口目标 i 至少要有一个满足同臂 F∧A 且连通的候选。

Q_i(e,x) = OR_(j,a) [ F(i,j,a) AND A(i,j,a) AND finite(D(e,j+1)) AND finite(D(j+1,x)) ]。

对目标窗口内全部任务要求 Q_i=1；窗口外任务不可服务仅记录诊断。此规则来自已版本化的 scope_r1。历史 S3_042 中，窗口内 23 个任务可行，窗口外 task221/table94 的两个候选处于安全膨胀障碍区，旧全父硬检查误阻断局部请求。不得重新套用旧规则，也不能以此放行真正不可行的窗口。[S05、S07]

### 4.3 目标函数与完整解

访问序列 τ=(e,v1,…,vK,x)，每个停靠至少新增服务一个剩余任务。当前可比指标固定为：

L(τ)=Σ D(v_t,v_(t+1))；J(τ)=L(τ)+0.75K。

0.75 是现有实验采用的等效距离停靠惩罚，不是实测秒数、能耗或机械臂动作成本。任务完成需提供 (task_id,candidate_id,arm) 证据，并且全部目标准确覆盖。

当前离散掩码下，每一步有正任务增益，动作数上界不超过目标任务数。单个任务两臂都可服务，不意味着可以重复计为两次完成。

### 4.4 MDP与奖励

状态至少包括父场景／局部任务表示、剩余任务、当前位置、入口出口和有序前缀。动作是选择下一个合法服务候选，不是自由输出未经约束的坐标。

合法动作 m_t(j) 要求：存在未完成目标可服务、当前点到候选可达、候选到出口可达，并满足给定安全条件。全部任务完成后终止；空任务须正确返回入口到出口的合法路径。

原科研环境已使用逐步移动／停靠负成本，终局加入出口及 H 修正，使 Σr_t=−J_H。不能再把“加入稠密奖励”写成凭空新增的研究贡献。新交接示例为简化接口，仅使用 raw 奖励 Σr_t=−J_raw，没有运行冻结科研 H。[S09]

已定位的参考为 Theile 等 ICAR 2021 论文《UAV Path Planning using Global and Local Map Information with Deep Reinforcement Learning》，作者代码 theilem/uavSim 的 icar 分支，固定提交 75316e8bf598820d1d3ef740de2321bed58f1076。[S04]

## 7. 输入／输出与数据交接规范

### 7.1 推荐的统一场景包

| 文件／字段 | 形状或内容 | 必须检查 |

### 7.2 完整方案输出

必须包含目标任务ID、访问候选顺序、候选停靠位姿、任务—候选—臂指派、入口出口、全局导航节点、连续折线路径、逐腿长度、J/L/K、方法角色、权重来源、H版本和验证结果。

本包示例 schema 为 rc3-handoff-plan-v1，动作使用局部0-based编号；历史科研环境的局部服务动作是1-based且0为符号端点。适配时必须显式转换，不能把两个接口混用。

科研侧导出 schema rc3-global-local-plan-v1 中 arm_joint_trajectories=null、physical_joint_trajectory_certified=false 的边界需保留。新示例同样不输出虚构的关节轨迹。

| v2–v5.1 | 规则与验证可靠，部分工程提速 | 不能把小幅学习收益或合法率当作稳定RL优势 |
| G系列 | 长期改进机会存在；窗口＋STOP学习未达目标 | 不重新包装同一STOP路线为第三部分新主线 |
| C系列 | 训练目标与最终H一致有条件性价值，但未改善起点 | “比另一组少退化”不等于获得有用模型 |
| R0 | 有界教师在32例相对gB+H平均改善2.2507% | 教师额外搜索收益不是神经网络收益 |
| R1／T1 | 动作价值排序、外推与蒸馏没有建立可靠收益 | 不靠Top1拟合或未知动作乐观预测代替完整评价 |
| S1／S2 | 教师、SL、三种子真实RL训练已完成 | 完成训练、loss下降、梯度有限不是性能证明 |
| S3 | 15874份成功计划代理有效；完整格中RL落后监督和强规则 | 两历史缺失不能解释全部完整格负结果 |
| GL-v4 | 轻量包保持输出；自然起点缓解原配方退化 | 未可靠改善SL／continuedSL，不应无依据扩大训练 |
| GL-v5 | 128更新、2480请求；G对三种学习对照raw/H后均退化 | 冻结贪心参考不是已成功的修复方法 |

GL-v5按12个父布局聚合，G的H后收益对共同SL为−2.8641%、对B为−2.4679%、对C为−3.2426%，区间均指向退化。其12布局属于训练过的物理环境，不能主要归因于新地图泛化。[S06]

GL-v4部署试验中，RL512轻量包每请求加载将完整冷／热导航中位耗时减少44.14%／53.20%；这只改变加载方式而不改变模型。常驻没有明确额外收益，SL256冷导航未提速。该结果不改写旧S3的部署失败。[S08]

这些数字来自不同协议和不同数据，不能跨场景直接相减当作模型演化曲线。完整报告／提交索引见 docs/EXPERIMENT_HISTORY.md。

第三，评审“冻结SL基座＋零初始化残差＋独立Critic＋受约束PPO”是否适合当前接口。老师可以否定或修订这项算法设计，但需提出仍以DRL为核心、可比较、可落地的替代方案。详见保留的未执行综合计划。[S10]

第四，制定一次性、有条件推进的研究任务：从集成检查、首种子训练、独立晋级到多种子确认。避免每轮只生成批准／准备报告，也避免失败后静默增加预算。

第五，评审论文贡献表述。双臂同臂约束、全父地图局部任务、快速冻结策略、规模适应性可以作为目标；只有实际匹配对照支持后才能写成已验证创新。

## 11. 新方案建议及尚未实现的模块

建议模型是冻结已有SL logits z0，加零初始化残差：zθ=z0+2tanh fθ，再用精确动作掩码。Critic使用独立参数估计当前状态的剩余回报。采用动作无关任务规模缩放、逐状态剩余回报、PPO概率比裁剪及SL锚定KL；部署只保留Actor。[S10]

这一组合是此前综合方案提出的设计，不是当前GL-v5已经运行的算法。本包learning_math.py仅实现可测试的mask、DDQN目标、PPO逐状态损失和零初始化残差头；它没有完成数据批处理、Critic训练、完整PPO runner、策略KL回滚、科研账本或正式checkpoint选择。

特别需要老师评审：按状态平均还是按轨迹求和会改变不同长度实例的权重；KL约束只在观测状态上检验，不是全状态理论保证；gamma=lambda=1保留终局H影响但方差可能仍大；冻结基座是否限制容量，不能在实验中偷偷解冻。

## 13. 验收、统计与性能定义

必须把三类判断分开：①输入／方案可行；②DRL独立收益；③质量—时间部署价值。完成路径不能自动推出优于基线，网络前向快不能推出完整规划快。

质量指标至少有J、L、K、准确覆盖率、逐臂可达违规数、碰撞／端点违规数、失败率。全部方法使用同一输入和对应计算流程；原生Fixed3／Detour不偷偷再加共同H，学习方法按协议统一H，RL_raw单列。

已有严格参考门槛包括：RL相对frozenSL和continuedSL均平均改善≥0.5%、配对区间支持正改善；相对Detour成本退化的单侧95%上界≤0.5%、完整中位时间比≤0.7、p95比≤1且不被Fixed3支配。这是历史协议的严格目标，不是已达到的指标。新的配方如需调整验收，须在评价前与老师明确，不能看结果后放宽。[S07]

以真实父布局为聚类单位。窗口、重复计时、三个优化种子不是独立环境数；说明seen/unseen、任务draw、endpoint和A条件。报告逐格结果和不完整格，不用总体均值掩盖某一规模失败。

计时覆盖请求输入／校验、导航准备、编码、构造、H、导出和独立验证；模型启动、缓存预热、审计维护和训练分别计费。冷／热导航与模型驻留不同。必须固定硬件、线程、软件和计时顺序；不得通过删除必要的安全验证制造加速。
