# 研究内容三：目标、问题与证据边界

本轮整理日期为2026-11-10。科研快照固定于`0c268426f3760f4d06596a29f65b3d1a5309987f`，不将持续变化的本机训练账本解释为闭合结果。分支和远端事实见[仓库审计](REPOSITORY_AUDIT.md)，逐阶段证据见[进度](RESEARCH_PROGRESS.md)。

## 固定研究目标

在大规模复杂多任务父场景中以深度强化学习训练规划策略，冻结后快速完成不同规模局部子场景的完整任务与轨迹规划，满足导航、覆盖、机械臂操作可达和安全约束。典型父场景为10×10百桌；4×3、6×6、8×8是局部目标任务范围，不是把父地图裁掉后假装完整环境。[原始目标](../rc3_global_local/RESEARCH_OBJECTIVE.md)

监督、教师搜索和规则可作初始化、辅助或对照，不能替代DRL核心。动态重规划、纯监督选择器和传统启发式优化不能直接取代这个固定课题。

## 技术流程

```mermaid
flowchart LR
    S[完整父场景与机器人代理参数] --> T[任务与局部目标集合]
    T --> C[候选停靠位姿及逐臂服务表]
    C --> D[绕障导航图与路径前驱]
    D --> P[覆盖与访问顺序规划]
    P --> E[展开底盘轨迹与任务用臂指派]
    E --> V[独立覆盖 路径 代理可达性验证]
```

停靠位姿包含平面位置、朝向和高度；任务必须具体指派到候选与某一只臂。目标不是输出若干停靠点就结束，还要给出访问顺序、入口出口、逐腿路径和完整任务分配。

## 当前可以展示什么

Fixed3与Detour是可靠的规则规划基线；二维代理导航、任务覆盖、可达性、导出和独立验证已有实现。本轮只复现一个新工程场景上的Fixed3与Detour16，不形成统计性能结论。新DRL方法仍需要同时证明相对监督初始化的学习增量、相对强规则的质量与完整耗时价值。[验收](HANDOFF_VERIFICATION.md)

当前为二维静态代理可达性实验。球壳/扇区可达表、矩形膨胀碰撞和F/A一致性不能认证真实双臂IK、双臂同步、关节碰撞、连续关节轨迹或实机安全。这些尚未完成；[机器人输入状态](../rc3_v5_1/README.md)与[交接材料缺口](HANDOFF_PACKAGE.md)列出后续输入。

## 三类结论分别判断

1. 工程可行：输入正确、完整方案通过给定代理验证。
2. 学习有效：同输入、同起点、同H下，DRL改善监督和其他匹配对照。
3. 部署有价值：满足完整质量门槛，计入导航、模型加载、后处理、导出和独立验证后仍足够快。

训练完成、loss下降、Top1提升、梯度有限和后处理H收益，均不能单独证明后两项。[结果与限制索引](EXPERIMENT_HISTORY.md)
