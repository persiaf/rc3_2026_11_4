保存的已知结论为：R03在128停止，ON/OFF完整路线未改变，256未恢复；C1数值改善C0但未全面胜条件常数；C2的组合value改善伴随H退化；多合法状态中约29.79%严格gap>.5；实际共同偏移能量约99.53%。新审计复算这些已保存数值不构成新增性能实验，也不读取原60或旧S3任务。

R04必须可证伪的问题：

1. C1在同归约、同批次、明确物理初始化差异及训练折常数对照下，能否在**两种**汇总口径保持校准优势？若不能，不能仅靠一个总体MSE推进联合训练。
2. `V_cond`是否在已有268维可观测条件上提供可靠而可迁移的锚点？若只在某折/某口径有优势，它不是必要结构。未知分箱要回退fit-only全局值，不能补入验证目标。
3. 预tanh的masked centering是否消除对所有合法logits共同加常数的自由度？这是代数/工程可验证命题。它**不保证tanh后均值为零**，也不解除`.5`首选间隔限制，更不保证有用排序或路线收益。
4. H信用可能修改历史路径前缀，268维观测未被证明Markov充分。不能把有符号终端H会计信用误当物理剩余距离，也不能将最终H/路线长度输入条件基线。
