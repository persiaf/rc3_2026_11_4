## 假设：旧结果没有证实的机制解释

| 待检验解释 | 与旧证据相容之处 | 当前证据边界 |
| --- | --- | --- |
| 限制策略漂移、保留 SL 锚能减少继续训练退化 | 多轮旧配置落后共同 SL，GL-v5 负结果明确 | 没有旧匹配试验证明 KL／残差是唯一解或必然改善。 |
| 状态价值 baseline 与 reward-to-go 能改善更新信噪比 | 原整回报训练缺少独立状态 Critic；尺度和裁剪诊断提示需研究 | 不把非零梯度、Critic loss 或 explained variance 当成路线收益。 |
| 按目标任务数缩放能缓解大任务对共享梯度的影响 | GL-v5 分尺寸梯度量级差异是已保存诊断 | 共享训练实例权重确实改变；并非与旧目标完全等价，也无已证实跨尺度优势。 |
| D1 与统一准备服务能降低完整交付开销 | D1 已有严格等价与局部时间证据 | 公共准备、H 与验证仍可能主导；不能由旧组件相减推算新速度。 |
| 存在可学的 H 后动作机会 | R0 有界教师有正机会 | 搜索机会不等于有限容量神经策略可在本预算中学会。 |

## 版本与结论边界

- [FUTURE_DESIGN_STATUS](../rc3_global_local/FUTURE_DESIGN_STATUS.json) 是冻结 v2 历史设计指针；实际已批准旧执行以 [ACTIVE_EXECUTION_STATUS](../rc3_global_local_execution_v3/ACTIVE_EXECUTION_STATUS.json) 和其授权收据为准。旧候选内的 PENDING 字符串、旧 NEXT_STEP 中当时的“未授权”不能覆盖后来收据或本轮明确用户任务。
- 本轮只新增 Integrated-RPPO 协议／源码绑定与当前任务来源；不回写旧 v2 指针、原授权、H 或历史角色文件。本矩阵不声称尚未生成的 SOURCE_BINDING 已冻结或已被用户逐 hash 审阅。
- 新方案性能主张 `claim_supported: no (not_tested)`；它表示本轮尚无实际新科学结果，而不是算法已失败。旧工程和有限机会主张分别保留为 scoped yes／partial。
- `paper/PAPER_CLAIM_AUDIT.json` 在本次预审检查时不存在。论文级推广仍为 provisional；这不是再次执行全部历史审计的理由，也不阻止已授权的有限研发。
- 本次 reviewer 的新增模型实例化／forward／backward／optimizer／导航／H／教师／任务生成／原 60 语义读取／旧 S3 任务输入读取均为 0。历史数值来自上述保存汇总，不冒称本 reviewer 已重算全部原始路线或全体验证其字节。
