## 2. 数学与算法一致性

### 环境、H 与 return-to-go

旧 [`Environment`](../rc3_global_local/environment.py) 的非终局奖励为 `-D(current,a)-0.75`，末动作加入出口代价与 `Jraw-JH`，所以总回报为 `-JH`。将每步同时除以动作无关的 `s(X)=max(1,N_target)` 得总回报 `-JH/s(X)`。这一缩放不改变同一固定输入的路线最优次序，但改变共享参数训练中实例间的权重，必须明确为新训练口径。

完整 episode、真实终止价值为 0、γ=λ=1 时，GAE 的 TD 残差望远镜求和恰为 `G_t-V_old(s_t)`。因此直接使用完整 reward-to-go 与用户设计一致，不需要引入 bootstrap 或回到整轨迹同一回报。末尾 H 修正留在每一个此前有效动作的后缀内，不会因折扣或 λ 沿长轨迹衰减。已经发生、在当前动作之前确定的奖励可从该动作的梯度估计中去除；H 的终局修正保留在后缀，不能把 H 改写后的动作序列当作原采样动作。

Critic 可以使用有限前缀表示作为 baseline；不要求它准确重建全部精确状态才有 action-independent baseline 语义。但它的误差、压缩表示与有限 PPO 更新均不给出贪心路线质量保证。禁止从“γλ=1”推导“Critic 一定准确”或“方差一定更低”。

空目标仍支付合法 entry→exit 成本、保存请求，但没有服务动作，不制造 Actor 梯度。空实例在 episode 平均中的既定权重、全空批如何关闭、Critic 诊断如何记账应写清，不通过重抽生成训练信号。

### PPO 的实际归约

令一批有 E 条完整 episode，第 e 条有 T_e 个有效动作。与任务书一致的 Actor 归约可明确写为：

```text
rho[e,t] = exp(logpi_current(a[e,t]|s[e,t]) - old_logp[e,t])
A[e,t]   = detach((G[e,t] - V_old[e,t]) / c_batch)
c_batch  > 0：全批一个固定标量；整个 PPO 批内不重算

L_actor = (1/E) sum_e sum_(t < T_e) {
    -min(rho[e,t]*A[e,t], clip(rho[e,t],.9,1.1)*A[e,t])
    + .02 * KL(pi0(.|s[e,t]) || pi_current(.|s[e,t]))
}
```

不能在每条轨迹内再除以 T_e，也不能把 padding 加入 E、步和、KL 或优势尺度。episode 均匀采样、有效步求和不是“每条长轨迹再获得额外声明外的采样概率”；它是总回报策略梯度的一阶形式。每步 ratio 是 PPO surrogate，不能替换成整轨迹概率比或旧 REINFORCE 全参数 loss。多个 epoch、clip、经验尺度与 Adam 后不再有严格无偏／单调性能保证。

统一优势尺度的具体公式和 epsilon 必须在首个优化前固化；例如只作统一 RMS 正尺度而不减均值，是可选择的工程口径，本预审不替执行协议静默选定。Critic 的 MSE 归约、warm 训练／验证划分和状态权重也应写明。将 Critic 拟合平均到状态不等于 Actor 可以改成 token 平均。

### 冻结与独立性

已查看的新 Actor 源码按 `202=3×64+10` 形成候选输入、两层 64 隐层与最后全零输出；Critic 为 268 维输入、两层 128 隐层。所用覆盖、稀缺度、距离、前缀、尺寸／端点特征属于部署已知量，未见教师 Q 或动作 H 补全成本泄漏。基础策略 `eval`／`requires_grad=False`、特征 detached 的方向正确。

这些是静态源码判断，不是已经验证的 bitwise logits／mask／greedy 等价。P0 必须实际证明零残差初始等价、基座文件及张量不变、Actor optimizer 只拥有残差参数、Critic optimizer 与 Actor／base 完全隔离。旧 [`Trainer`](../rc3_global_local_trainer/engine.py) 拒绝部分冻结模型并仅实现整回报 REINFORCE，因此新增真正 PPO 模块是必要实现，不能改名复用其训练语义。

## 4. 选择、暴露与晋级逻辑

新选择48例属于开发选择数据；旧S3、GL-v4/v5任务已经暴露，仅能作历史／回归。新晋级48与选择的任务及父布局分开。最终seen144与unseen72保持模型／配置冻结前不生成或评价目标语义；真实物理map_key及几何hash与seed标签分开，使用已存布局元数据排除混淆，不读取禁读旧S3目标任务。原60不消费。

选择上限1392的自洽拆解是：

```text
3 seeds × [SL 48 + RL (64,128,256,512) ×48
                    + residual-SL (64,128,256,512) ×48]
    + Fixed3/Detour16 各48
= 1392

晋级：3 seeds × [SL, selected residual-SL, selected RL] ×48
    + Fixed3/Detour16 各48
= 528
```

64轮仅作诊断；共同可选择集合是128/256/512。SL固定起点不重复生成检查点机会；规则每例一次质量结果供所有seed配对，不能算成三独立规则。各seed残差SL控制采用同一预登记候选机会与自己的SL谱系；对照的实际更新数、拒绝／回滚尝试和教师状态访问量分别报告，不能宣称等FLOPs。

P1的连续坏检查应明确解释为：64与128两次各自都出现三局部尺寸点收益全部负，且整体对SL收益<-2%，才触发此预定停止。单次负结果、区间跨零或某一尺寸负均不额外停止。128/256/512的候选按父布局等权H后相对SL收益最大选，先验证全部输入／数值／来源；并列优先较早。不得将64纳入事后候选。

P2的研究晋级与部署目标分开：按主执行者已选的明确化，候选对SL及匹配residual-SL的点收益均≥0.5%可进入预定三seed研究；不另外要求单seed显著区间，也不能因未达强规则部署目标就禁止存在RL增量的研究确认。部署目标必须继续单列并按原严格标准报告，不能提前宣布实用达标。

P3要求三seed候选全部冻结后对独立晋级集一次评价；均值／区间／seed方向的准确归约按协议预登记。晋级集一旦用于改配方便变成开发数据，不再给同一调整后的候选提供独立确认。最终比较保留未归一J/L/K、真实父布局单位、seen/unseen和尺寸／端点分列；不把窗口、重复计时或seed配对复制当成更多物理环境。

## 5. 总预算与条件消融

任务书上限算术自洽：`96+576+36864+1392+528+6048+3168=48672` 个顶层完整请求。32基础设施付费重试另计后仍低于50000；正式rollout为`512×24×3=36864`，每轮12问题、各2自然轨迹。P0若只注册60请求是更紧工程上限，不应将剩余额度转作研究搜索。

最终质量`216×(4×3+2)=3024`；计时`36×14×2×3=3024`。RL_raw／RL＋H若复用同一纯greedy路线，仍必须按已声明完整请求与各自真实时间／H调用分别记账；不能把raw缺少H的时间拿来承担RL＋H质量。三次重复是计时稳定性，不增加独立质量样本。

P5只有主方案出现可复现收益才执行，最多两项，每项64×24=1536训练终局及48选择评价。这里“相同前64轮数据”应指相同问题日程和预登记配对随机流；不同策略必须各自采样on-policy动作，不能免费复用主实验更新后的动作作为新策略数据。由于消融从相同π0出发，主实验保存的π0 warm episode可作为共同初始数据复用，不再生成额外终局；去任务数归一的Critic目标应按该消融尺度重算并在其独立拟合中计入optimizer／墙钟。不得复用不对应目标尺度的value标签并声称“其余相同”。

“去SL锚/KL限制”是联合移除组件的有限消融；保留PPO clip及其余已定机制，不能再把这一项结果单独归因为SL锚或某一个KL阈值。P5数据属于机制开发证据，不给出普遍理论保证，也不允许据此反向改写已经消费的最终确认。
