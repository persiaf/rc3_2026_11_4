# v5 维护与补充复验结果

2026-11-03。承接用户第四版验收材料。**默认仍是 Fixed3/Detour，旧 MLP 保留可选入口，Structured 保留研究入口。** 本版没有重新训练，也没有追溯改变 v4 的正式采用条件。所有新数值都注明平台、场景和分母。

## 外部共同约束修复

只修改导出用臂仍有遗漏：F-only 路线规范化可能提前删掉后续唯一被 A 允许的停靠。v5 用共同表 `F & A` 的 Problem 副本贯穿候选构造、Detour 修复、规范化和用臂分配，原 F、A 与证书保留。所有候选在通过双表终验、外部回调及内部/导出成本一致性检查后，才能成为初解或替换方案。

28/28 测试通过（9 原外部测试、11 上传补丁测试、8 新反例/守卫测试）；另有 5/5 CLI 检查通过。新增四任务反例中，原版和仅用臂补丁均误拒绝，v5 保留合法两站，J=12.8，Fixed3/Detour 均通过。没有将这一合成反例解释为真实机器人性能提升。

证据：`external_results/SUMMARY.json`、`canonicalization_counterexample.json`、`common_arm_counterexample.json`。A 已参与规划，结论仅为双表约束一致性；真实物理核验仍依赖有效输入与独立检查器。

## 旧 MLP：本机同软预算补评

复用原 18 个百桌测试场景，冻结原模型及运行代码；Detour 与旧 MLP 各 3 次随机交错，400 ms 软预算、256 步上限，共 108 次完整规划。所有方案独立有效且不劣于认证 Fixed3 初解，无回退。先在每场景内对三次目标成本取均值，再以 18 场景为单位做配对 bootstrap（20,000 次、种子 731203）。两方法各 54/54 次超过软预算。

| 本机 Windows 11 / Python 3.13.5 | Detour | 冻结旧 MLP |
|---|---:|---:|
| 相对 Fixed3 平均降本 | 1.472636% | 1.730254% |
| 完整规划中位数（场景内三次中位，再跨场景中位） | 437.383 ms | 436.144 ms |
| 全部 54 次耗时 P95 | 460.490 ms | 458.841 ms |
| 平均修复调用 | 19.833 | 18.278 |
| 有效方案/初解成本界 | 54/54 | 54/54 |

旧 MLP 相对 Detour 平均配对降本 **0.260507%**，95% 场景区间 **[−0.008684%, 0.529545%]**，胜/平/负 **12/1/5**。点估计正向，区间跨零；这次本机补评不能确认稳定优势。其实际规划中位时间接近 Detour，因此保留轻量可选模式，不能据此更换默认方法。

上传 Linux 补评也已独立重算：108/108 方案及成本界通过、36 条场景方法汇总一致。原报告旧 MLP 相对 Detour **0.288025% [0.026773%, 0.581804%]**、12/2/4 得到复现，耗时 449.379 vs 446.534 ms。**两个平台分开报告，不合并区间，不用 Linux 的正下界替代本机跨零结果。** 它们使用同一批 18 场景，并不是 36 个新环境或两个独立泛化测试集。

计时包括认证初解、特征/策略、修复、最终验证与推理线程会话；不包括模型加载、导航/可达性预处理、额外独立复验与保存。两项补评均为看到 v4 结果后的描述性补充；区间不包含全部训练种子或主机计时不确定性，没有多重比较校正。J=L+0.75K，是等效路程成本，不是实测任务完成时间。

证据：`mlp_budget_windows/`、`native_supplement_audit.json`、`uploaded_supplement_audit.json`，以及协议审核记录。冻结权重 SHA：`63e200f204b1e53c630f178bf7f60665944222becb60126b11c6461613db234d`。

## Structured 图嵌入缓存

沿用同一冻结 NPZ 和原 18 验证场景。正确性阶段 **144 次决策的三头输出和动作逐位一致，36 个完整计划对象相同且独立有效**。另行串行执行唯一一次完整计时协议：18 场景×2 实现×3 次随机交错，共 **108 个完整计划**，全部相同且有效。不是在计时阶段额外检查了 144 次输出；两套记录分开。

| 本机验证诊断，跨场景的场景内三次中位数 | 原版 | 缓存 |
|---|---:|---:|
| 完整规划 | 486.590 ms | 441.871 ms |
| 选择器整体 | 140.136 ms | 106.465 ms |
| 其中网络推理 | 75.449 ms | 36.356 ms |

两组中位数之比为 1.1012，按这两个数计算耗时下降 9.190%；逐场景配对耗时降幅的中位数为 **8.453%**，两者统计量不同。17 场景更快、1 场景更慢。不同阶段分别取中位数，不能将各列中位数直接相加。

本结果支持在静态约定下保持数值/路径等价并显示本机提速，不能外推为所有场景、主机或软预算下稳定提速。原主要百桌18场景、固定8次比较中 Structured 对 Control 的质量归因和原采用门槛未改变。不能拿这次验证集诊断与 v4 正式测试时间混拼后宣称通过 1.25 倍门槛。

证据：`cache_results/equivalence/`、`cache_results/benchmark/`、`cache_results/artifact_reconstruction.json`。缓存只复用静态图嵌入，动态状态、mask、输出头和 STOP 每步计算；不可变权重防止静默复用旧向量。F/D/语义变化要求新 Env；尚未实现运行中任务到达或地图变化。

## 真实 AlohaMini1 输入与回归

已下载并验证两份固定版本 URDF 与全部 19 个 STL，共 15,108,946 mesh bytes；两 URDF 归一换行后相同。13 个有界可动关节的 limit/velocity/effort 为零，不能用作真实操作范围。资产预检通过，但未填运行配置为 `blocked_inputs`。当前 135 个字段/派生一致性 blocker 表示缺输入，不表示 135 个物理缺陷。

新增输入清单、配置模板和预检 CLI；真实限位、零位、TCP、升降、夹爪映射、停放与碰撞约定仍需用户标定证据。**没有生成真实 F，没有运行真实 IK、机械臂碰撞或实体实验。** 15 项机器人测试是合成校验器测试；即使输入完整，也只表示可以进入后续服务见证生成，不能直接当作执行证书。
