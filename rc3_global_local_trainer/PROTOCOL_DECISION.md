## DRL、MDP与权重控制的准入条件

完整前缀、剩余任务、位置、出口和全局上下文属于环境状态，网络GRU只是压缩表示。当前动作必须有新增覆盖、当前位置可达并可到出口；逐臂F&A后再并集，禁止提前合并两臂。每条轨迹完成同一目标集和端点，不假定覆盖路径具有TSP循环对称。

对同一实例，三条独立条件轨迹的明确目标为`[E_primary R+.25E_forced_low R+.25E_forced_high R]/1.5`，`R=-JH`。主行完整动作logprob直接训练首动作；forced两行只训练条件后缀。其他两条独立回报的detached均值可作该行LOO基线；这不保证方差下降，更不保证冻结greedy成本改善。逐步`-Jraw`与终局`Jraw-JH`须精确合成`-JH`，不引入默认折扣/GAE/熵或未批准的优势缩放。

每seed应保存未训练权重，再完成唯一SL起点；冻结SL、RL和continued-SL必须从同一SL tensor逐位clone，后两者optimizer重置规则需按正式批准条款执行。独立模型实例、optimizer state、task-conditioned缓存与权重版本必须隔离。不能用“不同文件名”代替tensor/hash和运行中隔离测试。

连续与恢复运行须比较最终模型tensor、optimizer动量、RNG状态、后续样本/动作、训练计数和可恢复日志，而非仅比较最终loss。墙钟/RSS等天然运行观测不要求逐位相同；恢复时必须累计已花费墙钟，不能重置预算。源/协议/registry/H/模型架构/hash不匹配、重复输出目录或未知checkpoint应拒绝恢复。

## 推荐的正式训练预算与准入决定

建议批准完整v3执行条款或形成等价的新批准版本；在此之前仅保留v2作为活动冻结设计，**不选择“按v2缺省直接开训”**。建议不增加原主RL预算，不以本轮工程结果事后修改科研阈值：

| 阶段 | 推荐事前上限 |
|---|---|
| 共享S1教师 | 256份，一次nativeDetour16+一次共同H，最多512终局；1800s，三seed共享 |
| 每seed S1 | 256更新、batch4，1800s；固定CE与Adam配方 |
| 每seed S2 RL | 512更新、batch4×3角色，6144奖励终局 |
| 每seed continued-SL | 512更新，复用固定教师池，无新免费查询 |
| 每seed S2开发/其他 | 2048终局上限；与RL合计8192；共享7200s覆盖RL/继续SL/开发及IO |
| 三seed合计 | S1+RL+continued-SL最多3840optimizer更新；S2终局24576，另加共享教师512 |
| S3 | 仍封存；须后续对应授权，不由本轮技术验收自动解封 |

上述S1教师+三个S1+三个S2串行阶段墙钟上限合计28800s（8h），不是实际耗时预测，尚未涵盖任何未明确分配的前置数据准备。正式执行前须把数据/导航准备归属和全时间账固定；不得计为免费离线成本。先前未训练CPU探针约3548s/seed仅估RL核，排除继续SL、开发、准备和IO，不能承诺7200s一定完成。超限按协议停机，不扩预算或删除对照。

正式S1/S2的GO须同时满足：训练器完整实现；独立工程验收通过；完整源码/依赖/H/registry版本绑定；正式协议批准和执行授权存在；目标训练数据可行性/预算停机与保留测试隔离生效。缺少协议批准时，无论工程测试结果如何，正式阶段仍为**REVISE**。本轮不申请或执行完整DRL科学训练。

## 实现后仍须正式批准的文字澄清

工程验收已实际完成21次optimizer、12次真实H，全部独立于正式S1/S2。v2与v3原字节均未变；新`PROTOCOL_EXECUTION_CLARIFICATIONS.json`只是待批准的执行澄清提案，不能自动激活。

v3的S2.schedule概要仍称fixed sampling seed，而详细RNG_contract按protocol/optimizer seed派生data流；当前候选实现遵照后者，每seed独立可重放，并未声称三seed数据日程相同。正式批准须明确这一优先级，或另立不同日程版本并回归。数据/导航准备计入调用阶段，S2时钟覆盖SL载入、分叉、继续SL、开发和IO；同一run跨阶段当前绑定同一授权文件，不支持未经审查换授权文件后自动接续。以上都应在正式批准范围内明确，而非实验后解释。
