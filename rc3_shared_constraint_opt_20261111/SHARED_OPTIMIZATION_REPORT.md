## 唯一固定的局部子问题

保留实际float32原损失：

`mean_i relu(1e-4 + max_other_legal_logit - teacher_logit)`。

对每个合法非教师候选计算margin `m_ij=z_teacher-z_j`。每个外层求解：

`min_(d,s>=0) 0.001/2 * ||d||² + mean_i s_i`，约束为全部`m_ij + J_ij*d + s_i >= 1e-4`。

这是**带每状态slack的正则化软约束问题**，不是无slack硬分离证明。正则化、单一求解器、内层与切平面上限均事前固定。dual采用float64投影FISTA，每状态dual质量不超过1/32；每切平面轮最多5000次迭代，每外层最多16轮。用精确活动梯度行构造Gram，AD Jacobian方向积检查全部3961个合法替代候选；教师本身合法性也保留在全3993个合法候选检查中。

只有全问题dual gap≤1e-6、全部合法线性约束最大残差≤1e-6才COMPLETE。截断轮未完成时明确记录INCOMPLETE_NEEDS_CUT_OR_SOLVE，不用于实际方向试探；若达到求解上限仍未完成则停止，不能冒充完整解。
