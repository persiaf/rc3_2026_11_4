# 小规模精确参照独立复算

本目录是对原冻结小规模实验的复算，不是生成另一批新场景。

运行：

```bash
python -B audit_exact.py --source-root /path/to/extracted-v4 --output-dir /path/to/new-output
```

脚本从保存场景重建代理可达关系和导航图，对全部225份方案调用独立验证器、按折线路程加停靠罚项重建成本，并重跑45个场景与罚项组合的全局动态规划。27个独立场景中，44个组合取得optimal，1个18任务组合超过默认14任务上限而unsupported。保存状态、成本及5项协议源码哈希全部一致。

`summary.json`汇总统计；`plan_checks.json`逐方案检查；`exact_replay.json`逐组合重算；`reconstructed_metrics.csv`包含每个方案与最优参照的差距。

本轮另实际执行原`rc3_v4.test_exact`的7项单测，全部通过，含小规模排列穷举、有向度量、断开连接、空场景、非法输入及超时上下界检查。没有把44个最优组合写成44个独立环境。

## 数学范围

候选c的任务覆盖集合记为C(c)，任务数N、候选数M。状态V(S,j)表示覆盖任务集合S且终点为j的最小累计导航加停靠成本。初始化V(C(j),j)=D(0,j)+lambda。每次仅扩展增加新任务的候选k：

V(S union C(k),k) = min(V(S union C(k),k), V(S,j)+D(j,k)+lambda)。

全覆盖后加入返回起点距离。非负最短路度量满足三角不等式，停靠罚项非负，因此无新增覆盖的停靠可删除而不增成本；存在可由上述转移枚举的最优解。复杂度O(2^N M^2)、空间O(2^N M)。结论只针对给定F、D和有限候选，不是连续机器人运动最优性证明。

主罚项0.75下，取得证书的非空场景为25个。逐桌、固定集合精确排序、Fixed3、Detour8的平均离散最优差距依次为10.9323%、6.2186%、0.4498%、0.1017%。Detour8为24/25最优，不能推广为百桌0.1%最优差距。

算法有清晰的unsupported和软超时状态；超时保留可行上界与保守下界，不把超时或未支持写成最优。目标是长度加停靠等效米，尚未验证实际服务时间。
