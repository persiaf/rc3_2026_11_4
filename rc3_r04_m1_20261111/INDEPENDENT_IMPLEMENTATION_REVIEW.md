# R04-M1 独立实现审查

判定：**GO（仅本次明确授权的 M1 有界离线 C0/C1 校准）**。

审查者为独立子代理 `/root/m1_independent_review`。本审查通过读取源码完成，没有启动模型前向、优化器、轨迹恢复或历史完整审计。实际单元测试、数值复核与资源结论必须由本阶段登记后的运行证据给出；此处 GO 不预填这些结果，也不授予 M2、M3 或 Actor 事务许可。

## 审查中修正并保留的事项

1. 数据注册状态为`GO_METADATA`；执行器已按同一状态判断，避免误判无数据。
2. 保存端点的恢复记录使用`loaded_as_next_step_state`，不能把128因提前停止而没有发生的下一次更新写成已恢复续跑。
3. 预测CSV补充`remaining_fraction`，使独立审查能够重算条件分箱和fit-only常数，不能只相信已生成参照。
4. 资源predebit日志和资源文件在更新前flush/fsync；CPU Adam矩及step的设备/类型已明确校验。
5. 首次注册在元数据读取前发生重复`phase`关键字错误，optimizer和数据读取均为0。`PRE_REGISTRATION_FAILURE.json`保留错误、原ledger源码SHA和工具实测1.3070723秒；修复只移除重复参数，并将保守1.5秒及失败条目纳入同一累计资源账。未更换数据、参数或清零消费。

元数据锁定后复核：共116条轨迹（fit64、holdout52），仍为固定33fit父和16holdout父。四尺寸holdout父数依次为16/11/12/13，全部达到至少3父要求；12个缺失父×尺寸单元保留未补选。该结果只说明元数据覆盖可执行，不预判误差门槛。

## 独立数值复核范围

`independent_review.py`为本轮新实现，仅读取新保存的预测、指标、gate、训练日志、元数据和账本，外加前轮划分元数据。不复用生产指标函数、模型或loss，不重新跑训练。

它独立核对：物理父reserve哈希、共同批次、全部预测分量单位/value组合、初始化物理差异、fit-only常数及fallback、完整分尺寸/阶段双聚合指标、父布局配对区间、G3各项数值与状态、每个真实优化器slot及hash链。该复核应在同一1800秒计时内执行；审查失败保留已有消费，不追补配置或训练。
