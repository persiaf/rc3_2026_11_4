# Fixed3 初解上的多状态收益学习：v3 冻结实验方案

日期：2026-11-02。承接 v2 复核；旧108测试仅作回归证据，不参与本轮选模。

## 主张与判据

1. 在相同 Fixed3 初解、导航、覆盖约束、局部 DP、候选邻域和验证流程下，学习选择修复片段能提高有限预算的质量。必须分别以 DP 调用数和完整规划时间比较随机、几何绕行规则与学习策略；配对置信区间跨零则不宣称优越。
2. 已验证初解、组合可行中间候选、最终独立验证与失败回退保证代理模型内完整覆盖、合法路径及最终成本不高于 Fixed3。此主张不等于最优性、真实机械臂可执行性或硬实时。

## 方法和训练

- Fixed3 配方固定 (0,1,7)，先比较组合成本，再按成本顺序完整验证。
- 步长1，每起点取不超过4个停靠且必要任务不超过8的最大合法窗口；候选池上限80。三种选择器使用同一邻域和求解器。
- 失败缓存键为局部节点、必要任务、候选池，只缓存确定性无收益；成功后保留其他未变子问题的失败记录。
- 24维原观察增加剩余预算、已经用步数、当前/初始成本、累计改善4维，更新schema，不复用旧权重。
- 三类100桌场景各32训练、各6验证。混合教师、几何规则、随机轨迹，覆盖第0至7步，监督实际局部收益并保留零收益状态。
- Attention：64维、2层、4头；MLP：64维轻量模型。相同输入和收益回归、正收益辅助、含停止动作的排序目标。3种子17/29/43，每模型至80轮，每10轮用实际验证轨迹选检查点，不用训练loss挑选。
- 若监督模型有效，优先交付该模型。没有额外证据不将PPO加到部署主链，更不将收益监督称为强化学习。
- 训练数据存紧凑状态数组和场景，避免重复缓存整个导航对象。

## 核心实验

| 实验 | 设置 | 成功/失败解释 |
|---|---|---|
| 正确性 | 缓存反例、空任务、失败回退、成本与独立导出一致、padding/停止行为 | 任一失败先修复再训练 |
| 训练验证 | 两架构×3种子，仅100桌；记录所有轮次及选模 | 实际路线验证增益决定，不预设attention胜出 |
| 次数预算 | 1/2/4/8次DP；54新场景：12/36/64/100/144/196桌，各3模式×3种子 | 同求解器对比，报告全部组及CI |
| 完整时间 | 100桌冻结子集9例；验证后冻结3个时间档；包含初解、特征、选择、DP与最终验证 | 软时间上限，记录实际延迟及超时；不冒称严格等时或硬截止 |
| 可靠性 | 独立复验全部落盘方案和Fixed3成本界，失败分母保留 | 无验证通过则失败，不丢弃任务 |

计时方法随机顺序，重复3次取中位；预处理单列，冷总时间=预处理+完整规划；模型加载、进程启动、文件写入另说明。选模与时间档先冻结后测试。CI为场景配对bootstrap，不包含训练种子不确定性。相同检查点跨规模；物理参数与任务机制不随规模缩放。

## 执行顺序与预算

M0 修复及接口测试 → M1 生成多状态标签（主要CPU开销，预计数分钟至十余分钟）→ M2 六次GPU监督训练和独立验证 → M3 冻结模型与新测试 → M4 完整计时、独立审计和打包。GPU预算约0.2至0.5小时，按实际记录；不依赖未经验证的收益预期。

在数据生成前补充6个额外压力测试：256/400桌各3模式×1，与原54例分组报告，训练仍仅100桌。新冻结测试总数60；压力测试只检验外推行为，不冒称充分大样本。暂不加入真实IK、在线任务、容量、多机或任意地图。额外难度来自更大规模、混合桌面与通道障碍，以及更强初解后的修复。测试后不调参重测同一冻结集。

## 测试前验证诊断修订：停止判断

首轮6次训练归档于run_v3_20261102（11520更新，196.3秒）。仅验证诊断发现attention seed17主动停止13例中12例仍有精确正收益窗口；STOP与许多窗口放在同一个softmax后，低概率STOP也可比任一个被分散概率的动作大。原收益0.7468%，禁用STOP为0.9135%，但调用5.61增加至8，不能据此宣称效率提升。

正式版改为独立全局“无正收益”二分类STOP头：全部状态使用未类别加权的BCE，正收益状态参与窗口排序，全部状态仍做收益/正收益辅助。预先固定保守阈值0.9，不进行阈值网格，不称0.9为校准正确率。旧代码快照和原权重保留；用相同384状态、2架构×3种子×80轮重新训练至run_v3_stopfix_20261102，按新实际停止规则验证选模。直到最终模型、阈值和时间档冻结前，不运行测试清单。
