## 1. 原Critic的主要问题是什么

保存在线Critic的holdout value预测接近0，而完整回报明显为负：

| holdout口径 | 预测均值 | 目标均值 | bias（预测−目标） | MSE | 全局常数MSE | 条件常数MSE |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| state_pooled | -0.005358 | -0.880393 | +0.875035 | 1.639955 | 0.980112 | 0.324487 |
| parent_equal | -0.010018 | -1.124257 | +1.114240 | 2.233352 | 1.003733 | 0.451204 |

两种口径均劣于两种fit-only常数。偏差平方占MSE的已保存比例分别为0.4668945和0.5559041，说明系统偏差很大，但**并非全部误差只是常数偏移**。相应的平均父内居中误差仍为0.687183和0.733531。

归一化L/K/H分量均显著低估。state_pooled预测/目标均值依次为L 0.054225/1.646604、K 0.020878/0.376693、H 0.064525/1.048731；parent_equal为L 0.088360/1.896790、K 0.033930/0.381089、H 0.103790/1.058349。不能只看分量单位不同的raw损失绝对值排序。H是对整条raw路线的有符号终末信用，不是剩余物理距离；组合value中的L、K、H会发生误差抵消，分量变好不保证value同步变好。

分层表显示偏差也具有明显条件结构。例如保存在线Critic的parent_equal value MSE：4x3早/晚为2.836441/3.341235，10x10早/晚为0.992362/0.869496；相应预测均值仍接近0。8x8早期MSE为3.493863。故合理诊断是：**原头的有效输出尺度及条件校准不足，同时保留父内/状态条件误差**。不能归结为单一全局偏置，也不能从相关性直接认定某个表示字段缺失就是根因。分层父数仅1–5，不能作普遍尺寸规律或显著性断言。

## 2. C1/C2是否改善holdout

下表完整列出两种聚合、各自初始化、256步终点及fit-only常数。数值为已保存表的转录，未重新计算。

| 模型/终点 | state_pooled value MSE | parent_equal value MSE |
| --- | ---: | ---: |
| C0 / 0 | 1.619299 | 2.202408 |
| C0 / 256 | 1.170964 | 1.442635 |
| C1 / 0 | 0.864247 | 1.013953 |
| C1 / 256 | 0.493636 | 0.573995 |
| C2 / 0 | 0.864247 | 1.013953 |
| C2 / 256 | 0.351675 | 0.418058 |
| fit-only全局常数 | 0.980112 | 1.003733 |
| fit-only窗口×可观测进度条件常数 | 0.324487 | 0.451204 |

C1、C2在两种口径均优于各自初始化、C0终点及全局常数。C0虽较其初始化改善，两种口径仍劣于全局/条件常数。不能把C1/C2相对C0初始化的全部改善归因于优化：C1/C2在第0步已具有明显不同且更好的value MSE。

C2相对同起点C1进一步降低两种口径的value MSE，且分层表中每个窗口×early/late终点的value MSE均低于C1。但是最强常数比较不一致：**C2 parent_equal 0.418058低于条件常数0.451204，而state_pooled 0.351675仍高于条件常数0.324487**。C1两种口径均未胜条件常数。C2在fit上的两种value MSE（0.295820、0.548233）也仍高于相应条件常数（0.185094、0.360990）。因此不能写“所有口径胜常数”或“已充分学到状态条件价值”。

组合value项也存在分量取舍。下面是已保存表中最终holdout H MSE的精确转录：

| H表示与聚合 | C1 / 256 | C2 / 256 |
| --- | ---: | ---: |
| normalized_H / state_pooled | 0.08770585385603788 | 0.14383114443792216 |
| normalized_H / parent_equal | 0.14157969336271917 | 0.17162508288928463 |
| terminal_H_credit原单位 / state_pooled | 666.0221451095787 | 2307.0885695867332 |
| terminal_H_credit原单位 / parent_equal | 391.1943286936655 | 977.6335347261967 |

C2比C1的H MSE在上述两种表示和聚合均变差；归一化L、K则改善。C2的H两口径均劣于全局及条件常数。C2并不支撑“全部剩余成本分量均更准确”。现有结果支持**在本次固定离线设计下，归一化参数化和增加value项可以改善数值校准；优势取决于指标和参考常数，且value项有分量代价**。

## 3. ±0.25界在多少状态理论上无法翻转top1

对同一合法候选集合，每个残差属于[-0.25,0.25]，两候选差最多0.5。因此只有**base top1−top2严格大于0.5**才构成任意允许残差均无法翻转的充分条件。等于0.5至多触及平局，不能并入严格不可翻转计数；小于等于0.5只表示理论上有可能，不保证当前头会翻转。

保存统计：8150状态中，8144个有多个合法动作，2426个满足严格gap>0.5；对应已保存比例为全状态0.2976687116564417、多合法状态0.29788801571709234。**另有6个单合法动作状态**，不存在合法替代动作，应单列；包含单合法与严格锁定的合计比例为0.2984049079754601。不得称“全部/多数状态都被±0.25锁死”，也不得将这约三成的理论充分条件解释成其余状态的因果解释。

## 4. 实际共同偏移是否主导Actor无响应

保存的实际残差state_equal能量中，共同偏移比例为0.9952877456825568；未居中RMS为0.00039345758127726146，候选内居中RMS仅0.000027009234677388398，最大候选跨度0.0002198127913288772。**在此统计口径与这批保存状态上，共同偏移主导**。共同加到合法logit的常数在softmax及排序中抵消，真正影响决策的是很小的候选间居中差；它与仅约三成状态具有严格理论锁定共同解释“有更新但决策几乎不动”。

pre-update ratio单列为1.0；post-update ratio范围0.9999963517953163至1.0000036894605966。二者不能合并。post-update共有92个状态完整排序发生变化，但top1变化为0，说明局部排序确有响应，尚未跨越最佳动作；不能说Actor完全没有数值或排序变化。ON/OFF特征切换以及固定相同权重的配对top1变化也均为0，只对已保存状态成立，不能外推到所有未来状态或宣称206维输入永远无用。

这是有直接数值支持的机制描述，**不是对原训练失败的完整因果证明**。当前没有将“消除共同偏移”作为单一干预后重新训练的证据，也没有证明增加幅度、学习率或轮数能产生正确而安全的排序。原R03所有候选被接受且无guard拒绝，不能归因为guard拒绝；本轮也不能把零top1变化自动归因为残差界本身。

重建限制显式保留：原始206/268维feature tensor和完整候选logit未持久化，前者依确定性保存前缀重建、后者依精确源码绑定的before-checkpoint恢复；实际选中logit与概率分别按1e-6、2e-6容差核对，数值复核PASS。原Critic预测无缺失。重建不是原始tensor直接保存，应作为可追溯但非原始持久化证据说明。

## 5. 下一版只建议改哪一处，证据够不够

**唯一优先修改建议：将原R03 Critic的输出参数化从C0改为C1，直接预测固定initial_n归一化的L/n、K/n、H/n；本轮不同时加入C2的value项，不修改Actor、残差界、guard、输入特征、场景分布、H或训练轮数。**

理由是原头的尺度失配证据明显，C1在两种holdout聚合均优于C0终点及自身初始化，而且这是相对于原R03最小、可解释的单因素修订候选。现有证据**足以支持把此修改写进候选协议与实施审查**，不足以直接批准正式训练，更不足以预测路线收益。必须说明C0/C1的物理初始化不同；若未来要作“纯尺度优化效应”的因果主张，还需在新授权协议中预先定义物理预测匹配初始化的控制，不能把本轮追认为该控制。

C2的同初始化对照为value项提供更干净的离线改善证据，但相对原R03同时引入C1参数化和value项会变成两个因素，且H分量退化、pooled仍未胜条件常数。本审查因此不把C2直接替换原头包装为“只改一处已证实成功”。value项可作为后续独立因素候选，**不是本轮追加运行建议或授权**。若以后选择C1→C2路线，必须明确C1是固定对照，而非声称已隔离R03→C2的单因素效应。

## 结果到主张字段

**what_results_support**

- 保存在线Critic存在很大的有效输出尺度/系统偏差及条件校准不足；不只是常数偏差。
- 本次离线C1/C2改善留出父布局数值校准；C2进一步改善组合value但有H分量代价，并仅在parent_equal胜条件常数。
- 约三成状态有严格残差界充分条件，单合法状态另列；实际残差几乎为共同偏移，92个完整排序变化且top1全不变。

**what_results_dont_support**

- 任何路线质量、完整成本、规划时间、DRL泛化、真实IK/关节轨迹或实机收益。
- 全口径/全分量胜最强常数，或归一化及value项已隔离解释原在线失败全部原因。
- Actor被guard拒绝、全部状态被幅度界锁死、特征永远无用，或放宽幅度/延长训练必然有效。
- 将本次离线holdout当成全新未见DRL父布局，将状态数当独立样本数，将保存在线checkpoint汇总当第4拟合配置。

**missing_evidence**

- 物理初始预测匹配的参数化对照；多个预先固定分组/初始化上的稳健性与按父聚类的不确定性证据。
- 对条件常数的state_pooled稳定优势及全部分量的校准证明；目前部分指标明确没有优势。
- Critic单一改动进入在线DRL后对优势、有效top1、完整raw/H路线成本及时间的因果链，未来须以新协议、明确权限和原边界取得；当前没有。
- 对共同偏移的独立干预证据，以及其与学习到有用排序之间的因果关系。
- 论文级PAPER_CLAIM_AUDIT，当前不可用。

**suggested_claim_revision**

> 在128条历史R03训练轨迹、50个物理父布局的预登记离线诊断中，按物理父布局划分的33/17拟合/留出设置显示：直接预测initial_n归一化分量改善固定预算Critic的留出校准，加入组合value损失进一步降低value MSE；后者在父布局等权口径优于fit-only条件常数，但状态池化口径仍未超过该常数，并牺牲部分H校准。保存Actor状态中约三成具有±0.25界下的严格top1不可翻转充分条件，实际残差能量主要为不影响排序的共同偏移，少量完整排序变化未改变top1。这些结果为离线数值与响应机制证据，尚未建立在线DRL路线收益。
