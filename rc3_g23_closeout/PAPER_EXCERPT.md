# 方法筛选与机制诊断：可用表述

本文件为收尾文字素材，未直接修改论文。统计来自冻结的 G2.3 记录及本轮只读复算。建议将本系列作为方法筛选与机制诊断材料，不能据此宣称第三部分 DRL 核心有效性已经成立。

在规则操作可表达性对齐的条件下，本研究实现了基于冻结继续策略的有限多步价值评价与策略改进。实验包含三个训练配置，每个使用不同的四个训练场景；每个最终多步模型经历 512 次优化更新，三个种子和全部对照合计 3,840 次更新。测试包括六个独立新场景，每种方法重复两次，全部方法共保存 180 份规划输出。其中 36 次为多步模型测试。任务可达性和路径可行性均处于声明的二维静态代理模型范围内。

| 多步方法的比较对象 | 平均相对 J 改善 | 95% 场景配对区间 |
| --- | ---: | ---: |
| 同接口规则 | −0.2661% | [−0.5278%, −0.0626%] |
| 重复一步价值 | +0.0517% | [−0.0994%, +0.2252%] |
| 冻结初始化 | +0.1814% | [+0.0205%, +0.3523%] |
| 等更新静态规则价值 | +0.1594% | [+0.0205%, +0.2999%] |
| 原 Detour16 | −1.0884% | [−1.6967%, −0.5172%] |

表注：`J=L+0.75K`，为路径长度与停靠次数的加权成本，不等于实际任务总时间。正改善表示多步方法成本更低。先在场景内平均三个种子和两次重复，再以六个场景做配对 bootstrap；表中保留原报告的 10,000 次重采样区间，完整枚举经验重采样分布后门槛判断不变。该区间未独立估计训练种子不确定性。

相对等更新静态控制的 0.1594% 正增量表明，在本次有限实验中存在学习增量；但五项比较均未达到预设的平均改善至少 0.3% 且区间下界大于零的质量门槛。相对一步模型的区间跨零，对强规则的平均改善为负。因此，这些结果不足以支持多步价值学习已形成优于强规则的实用方法。

| 36 次多步测试的质量与时限联合分布 | 完整时间 ≤0.8 秒 | 完整时间 >0.8 秒 |
| --- | ---: | ---: |
| 严格优于同场景、同重复 Fixed3 | 0 | 7 |
| 未优于 Fixed3 | 22 | 7 |

表注：严格改善定义为 `J<J_Fixed3−1e−9`。本表使用全部 36 次记录，不剔除超时样本；0.8 秒是完整规划软预算。22 次按时结果全部与 Fixed3 等成本，7 次严格降本结果全部超时。平均降本与合并时间中位数不能解释为单次规划同时获得两者。

机制检查显示，种子 2302 第二轮保存的 12 条一步与多步后缀逐条一致，实际继续策略在首修复后停止。因此，即使该训练配置在测试中产生了质量改善，也不能将其解释为长程收益利用或越谷机制已经成立。另外两个训练配置的第二轮多步目标均为负，其测试全部选择停止。不同训练配置同时改变了训练数据子集和训练随机性，现有结果无法单独辨别两种因素的贡献。

综合质量、时间与配置差异，本研究按预登记约定结束当前局部窗口选择＋STOP 路线的追加训练，保留 Fixed3／Detour 作为默认规划方法，并将本实验归档为有限策略改进与方法选择的诊断证据。该结论限于所测模型、预算和场景，不能推广为深度强化学习或局部搜索普遍无效；真实机械臂标定、IK 和双臂协同执行不在本实验验证范围内。

数据入口：`outputs/results.json` 中的 `main_comparisons` 与 `proposed_method_joint_quality_time`；`outputs/model_budget.json` 中的 `fits` 与 `labels`。完整版本历史、逐条审计与路径记录见原 G2.3 交付包。
