# 保守PPO后机制诊断：五项回答

本轮已完成128条保存轨迹、8150个动作前状态的Actor诊断，以及C0/C1/C2各256步离线Critic拟合。样本来自50个既有R03训练物理父布局，33个fit、17个完整父布局holdout；不是新独立场景测试。精确样本和共同日程在首次前向前登记于[PREREGISTRATION.json](PREREGISTRATION.json)。R03的128停止、256未开始、原成本/时间及负结论全部保留。

独立数值复核：[NUMERICAL_RECHECK.json](NUMERICAL_RECHECK.json)，41,591,999项检查全部PASS；覆盖全部状态、1,602,480条合法候选、Critic逐状态分量/汇总、fit-only常数与768条共同批次更新记录。该PASS证明导出数值内部一致，不能代替真实规划性能证据。独立主张判断见[INDEPENDENT_MECHANISM_REVIEW.md](INDEPENDENT_MECHANISM_REVIEW.md)。

**1. 原Critic主要是整体偏差、尺度问题还是分状态误差？**

量级偏低是明确现象，同时存在布局相关和状态相关误差。本轮17个holdout父等权的原保存在线预测中，L预测均值3.6474、标签111.4196；K为1.3937对25.7455；H信用为4.3290对71.3276。组合value预测均值−0.0100，目标−1.1243。它们来自沿训练过程变化的原Critic检查点，作为描述性诊断，不是第四个匹配拟合配置。

原value父等权MSE为2.23335，整体有符号bias为+1.11424，整体bias²占MSE的55.59%；按父内部作分解，父bias²均值1.49982，加父内中心误差0.73353，恰为总MSE。state-pooled口径整体bias²占46.69%。因此不能将问题归为一个全局常数偏移，也不能由此证明268维条件信息必然不足。分量参数化、目标尺度和组合监督都有可检验作用，剩余条件误差仍明显。

上述新子样本、折划分与聚合口径不能替换R03原停止指标。完整分量及两口径结果见[CRITIC_MATCHED_CALIBRATION.csv](CRITIC_MATCHED_CALIBRATION.csv)；窗口和阶段见[分层表](CRITIC_STRATIFIED_CALIBRATION.csv)。

**2. 归一化参数化和value直接损失是否改善留出父布局？**

以下均为固定第256步、同一17个holdout父、同一保存状态的value MSE：

| 配置/参照 | state-pooled | 父布局等权 |
| --- | ---: | ---: |
| C0：原raw分量参数化/原分量损失 | 1.170964 | 1.442635 |
| C1：直接预测L/n、K/n、H/n | 0.493636 | 0.573995 |
| C2：C1加入组合value损失，系数1 | 0.351675 | 0.418058 |
| fit折全局常数 | 0.980112 | 1.003733 |
| fit折窗口×可观测进度条件常数 | 0.324487 | 0.451204 |

C1/C2都改善C0并胜全局常数，C2优于C1。C2只在父等权总表胜条件常数，state-pooled仍未胜；不能挑一种口径宣布全面通过。分窗口中C2仍未在10×10、6×6、8×8各阶段稳定胜条件常数，4×3两阶段较好；部分层只有1个holdout父，不能作稳定泛化判断。

C2还存在分量取舍：归一H信用MSE在pooled/父等权下，C1为0.087706/0.141580，C2为0.143831/0.171625；原单位H信用MSE也在两口径退化。不能只用组合value下降代表L/K/H全部校准变好。

初始化也必须保留：C0的父等权value MSE为2.202408，C1/C2均为1.013953；state-pooled分别为1.619299和0.864247。三者净张量相同，但C0输出raw单位，C1/C2输出per-n单位，故初始物理预测不同。结果支持这一固定参数化与损失配置的离线改善，不能把全部差异归因于训练梯度或只归因于新value项。

条件常数仅由fit父布局估计，使用窗口和现有v[256]可观测剩余任务比例；不使用最终轨迹长度、不读取验证均值。三组统一state mean→trajectory/batch mean，区别于旧PPO的state sum；本轮不回写旧损失或原停止口径。

**3. ±0.25在多少状态上理论上不能翻转首选？**

对两个合法候选，残差差的闭界为0.5。8150个状态中，6个只有单一合法动作，另列；8144个多合法动作状态中有2426个基座top1/top2间隔严格大于0.5，占29.7888%。这些状态无法通过当前结构改变唯一top1。等于0.5只可能达到并列，需保留原tie规则；不将它混入严格不可翻转数。

余下状态并不保证实际会翻转。实际残差远未达到结构界，且本轮没有放宽±0.25。[ACTOR_RANK_RESPONSE.csv](ACTOR_RANK_RESPONSE.csv)保留逐状态间隔、理论界与单合法标记。

**4. 实际残差是否主要是无效共同偏移？**

是，针对本轮抽样状态及各自更新后的实际Actor。以状态等权平均的残差能量分解，共同偏移占99.5288%；这是能量比例，不是状态比例。原残差范围约1.4786e−5至8.0697e−4，总RMS3.9346e−4，去共同偏移后RMS2.7009e−5，最大候选间span2.1981e−4。共同平移不改变softmax或排序，导出同时保存真实tanh残差及float32有效logit差，避免相减精度掩盖。

实际更新前后首选变化为0/8150；92个状态发生局部候选排序变化。更新前actual-action ratio严格为1，更新后范围[0.9999963518,1.0000036895]，分别保存；不能用更新前ratio为1判断没有学习。固定状态上的ON/OFF权重比较及两个mean/max特征开关比较均未改变top1，但这不证明这些特征在任意训练配置下都无用。

完整合法候选、概率、排序和残差在[ACTOR_CANDIDATES.csv.gz](ACTOR_CANDIDATES.csv.gz)中；该文件约448MB，沿Git LFS保存。本轮仅复用历史更新前后权重，Actor optimizer为0，没有重算路线或H。

**5. 下一版只需改哪一处，证据够不够？**

独立审查建议把唯一首选改动限制在**C0→C1的Critic输出归一化参数化**：直接预测per-initial-n分量，保留原分量损失的等价目标，不同时加入C2的value项。268维输入、冻结SL、原Actor结构与±0.25界、H和奖励保持原设置。C2相对固定C1的value项开关已经有干净离线比较，应保留其value改善及分量取舍，不能把直接C0→C2称为单因素。具体边界见[NEXT_MINIMAL_REVISION.md](NEXT_MINIMAL_REVISION.md)。

现有证据足以支持将C1列为比原C0更合理的最小离线候选，尚不足以恢复联合PPO或声称路线收益。C1仍未胜条件常数，C2也未全面胜条件常数，误差还分布在状态/布局层面；Actor实际修正主要为共同偏移，Critic改善是否能改变有效排序没有被实验验证。独立主张结论为partial（无论文主张审计，provisional）。本轮不同时增加特征、改Actor界、加轮数或另选配置。
