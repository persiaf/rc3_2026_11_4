## 缓存实现的审查结论

缓存命中条件为同一Env、完整路线相同、有序窗口起止布局相同。新Env、路线变化或窗口变化重新编码；同Env中替换problem、F、导航成本对象或scene会明确拒绝。每步仍重新计算28维统计分支、动态mask、排名、收益头、正收益头和STOP池化。

相比上一轮隔离适配器，v5为固定权重增加了API防护：数组由不可写bytes承载，不能将writeable标志改回；权重映射和metadata冻结；公共model属性和关键配置字段不能直接替换。11项测试实际覆盖这些约束，也覆盖control检查点和拒绝PT。

此防护是正常API约定，不是防恶意Python反射的沙箱。F/D和嵌套scene的原位改变不逐动作哈希，必须遵守整个Env内静态的前提。invalidate只清适配器自身，不能刷新旧Env内部缓存；在线新任务或地图变化应重建problem与Env。代码及文档已明确这些限制，没有将缓存宣传为动态任务到达能力。

未发现上述合法静态输入契约内需要修复的缓存计算错误。上一轮适配器修改权重后的反例属于违反其已声明契约后的缺少防护，不能用它否认原静态输入下的等价结果。

## 本机缓存计时的统计重建

18个原验证场景，原版与缓存各3次交错，共108份完整规划。以下为先取场景内三次中位，再跨18场景取中位：

|范围|原版 ms|缓存 ms|
|---|---:|---:|
|完整规划|486.590|441.871|
|选择器整体|140.136|106.465|
|其中图输入处理|68.886|67.810|
|其中推理|75.449|36.356|

两总体中位数计算的耗时下降为9.1903%，速度比1.1012。逐场景配对降幅的中位数为8.4528%，配对速度比中位数1.0924；17场景更快、1场景更慢。四种聚合不可互换，分项中位数也不能直接相加。

36份正确性方案、108份计时方案不仅在同一阶段内一致，两个阶段同一场景的方案对象也一致。此结果支持本机静态约定下复用计算并减少耗时；不构成全部主机、全部场景或软预算情形的稳定提速保证。

计时包含认证初解、特征、模型、修复、终验和线程会话，共同预处理、模型加载、额外复验与I/O另计。该验证集诊断不能与原v4百桌正式测试的427／275 ms拼接，也不改变结构模型对Control的质量区间或原采用门槛。

## 旧 MLP 的本机同软预算结果

18个原百桌测试场景，400 ms软预算、256步上限，两方法各3次交错。每场景三次成本取均值、时延取中位，再做场景配对统计：

|指标|Detour|冻结旧 MLP|
|---|---:|---:|
|相对Fixed3平均降本|1.472636%|1.730254%|
|完整规划中位 ms|437.383|436.144|
|全部54次耗时P95 ms|460.490|458.841|
|平均修复次数|19.833|18.278|
|超过400 ms次数|54／54|54／54|
|回退|0|0|

旧MLP相对Detour平均配对降本为 **0.260507%**，95%场景bootstrap区间 **[−0.008684%, 0.529545%]**，胜／平／负为 **12／1／5**。20,000次重采样、种子731203及排序规则的重算均一致。

结果应写成“轻量模型存在小幅正向点估计，但本机区间跨零，尚未确认稳定优势”。区间跨零不证明模型无用，区间负下界也不能靠另一平台的正下界替换。

软预算仍有随机计时影响：Detour的17／18场景在重复之间调用数变化、7／18成本变化；MLP分别16／18与9／18。区间以场景聚合量为条件，未完整覆盖计时、训练种子和硬件不确定性。不能把400 ms参数称为硬实时返回保证。

历史Linux补评使用完全相同的18个场景和模型哈希。其摘要仍为+0.288025%、区间[0.026773%,0.581804%]；本次只重读该历史manifest和摘要，未重复其108份历史计划验证。两个平台不能合成36个新场景，也不构成两套独立泛化数据。旧MLP继续可选、Fixed3／Detour继续默认的决定与现有证据一致。

## 可移植性说明

缓存manifest中cache_diagnostic.py与policy.py两条源码记录是旧Windows绝对路径，原内部verify_cache_artifacts.py直接读取该绝对路径。迁移机器后直接运行这一内部脚本会找不到旧位置。这个问题只影响该历史证据重算入口，不否定原数值或规划入口的迁移检查。

本次审查脚本通过显式--relocate-from指定manifest中已知旧项目根，映射到当前--source-root后核对原SHA；67项全部匹配。没有按同名文件猜测来源，也没有删除或更新原manifest。

```bash
python -B audit_cache_stats.py --source-root /path/to/extracted-v5 --output-dir /path/to/new-audit --relocate-from 'D:\file_used\西柚\实验室_任务\硕士论文相关\大论文\chatgpt生成文件'
```

日后维护该内部重算入口时，可以沿用原rc3_v4.audit.resolve_reference的显式根目录迁移能力；无需另开模型训练或性能实验。原审计包保留历史路径，新增运行记录写新目录。
