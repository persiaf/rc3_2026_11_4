## 机器人资产与隔离补丁

两URDF归一换行后一致；19个二进制STL共15,108,946字节，大小/SHA/Git blob与保存清单吻合，面数与字节长度匹配，顶点和法向有限。实际inventory返回assets_verified/0；未填模板check返回blocked_inputs/2，135个字段与派生一致性阻断项与原报告相同。

13个有界可动关节的lower/upper/velocity/effort均为零，不能作为真实运行限制。资产完整性、配置一致性与IK/碰撞认证是不同层级。135 blocker不表示135个物理故障。此轮未重新联网认证上游、未填真实值、未标定、未求IK、未运行真实碰撞或机器人。

发现的窄问题：在合成fixture中互换夹爪role、引用和park集合，实际URDF仍挂在原左右臂，原预检却返回inputs_complete。补丁检查夹爪关节实际祖先链，要求在本侧运动臂和升降之后、不能包含另一侧臂；固定工具连接仍允许。反例修复后返回blocked_inputs，真实空模板报告逐字段不变。

补丁位于robot_patch，含修订robot_input.py、unified diff、19项回归记录和前后反例。需要采用时在单独开发副本合入，记录新文件哈希；不修改原冻结实验清单。

## 论文使用决定
