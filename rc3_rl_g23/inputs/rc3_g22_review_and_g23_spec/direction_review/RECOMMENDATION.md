# G2.2 后的方向判断：只保留一次有明确止损条件的多步纠偏试验

本审查只读 G2.2 保存证据、报告和评估源码；没有导入规划器，没有环境调用、训练、推理或新测时。数字来源为 `outputs/report_table.json`、`outputs/evaluation/*/evidence.json.gz` 和 `EXPERIMENT_RESULT_TO_CLAIM.md`。下文的下一轮流程是设计，不是已执行结果。

## 1. 结论

**优先路线：让原 Detour 的逐步决策成为显式候选，用一个预算条件化的深度价值模型学习何时偏离规则、选哪个局部操作、何时停止。保留当前局部改进框架仅做一次封顶试验，不继续追加当前 CE+收益权重训练。**

当前问题不只是 STOP 不准。原 Detour16 在全部 12 个场景中取得比两个学习策略更低的 J；CE+收益仅执行 15 次提案，而原 Detour 执行 192 次，二者的操作、菜单、工作记账也不同。因此这些结果既不能证明“神经网络不适合规划”，也不能证明“只要多搜索就能追上”。需要先确认网络的候选动作是否能表达强规则的有效操作，再在同一动作与资源接口中学习多步纠偏。

简单修补 STOP 无法解决质量差距：返回值是已经验证的最好路线，沿已实现的动作序列提前停止只能保持或提高返回 J，不能产生原轨迹未到达的更好路线；它可以节约计算代价。case 0 的成功后过度继续支持改善停止，case 8 支持不能把负绝对后缀当作负停止优势。这些证据没有证明 PPO 增量。

**case 1 还不能承担“必要的长程决策”证据。** CE+收益的第一步没有改变 current 或 best；第二步成功动作 `improve:5:9:-` 在根菜单中已经合法存在，且与根部对应 proposal key 相同。没有执行根部反事实，不能断言在那里一定取得同样收益，但记录更直接支持“先选错，再选中”，而不是证明首步为后续成功打开了新路径。两学习策略真正让 current 变差的提案只有 3 次，全部在 case 7，之后均未改进 best。因此 G2.2 尚未证明非短视策略的必要性；必须用同资源的一步价值选择作为关键对照。

## 2. 当前错配有三层

### 2.1 可选动作与比较对象未对齐

共享根菜单是 8 个 improve 与 8 个 replace 加 STOP；原 Detour 的 16 次修复不是从这个菜单依次挑 16 次。原 Detour 证据包含内部数值 action 索引和成本轨迹，但没有每步完整路线、具体操作参数与共享菜单。**仅凭这些索引无法判断其优势操作是否在学习菜单中**，也不能把同号 action 视为相同操作。

下一轮第一项应是逐步候选覆盖审计：对原规则每一个状态，记录原规则下一操作的语义键、路线前后、约束和可行修复语义，与同状态菜单比较。菜单不覆盖时先将这一个规则操作加入候选，不扩大整个菜单规模；状态必须加入原规则所需的游标或尝试记忆。若包含规则操作仍不能用相同转移复现规则轨迹，先停止训练，解决转移接口差异。这里复现的是相同预算允许的轨迹或前缀；不能要求受 2,000,000 共享工作量限制的环境无条件复现没有这项记账的原 Detour16 完整运行。覆盖不足不能靠更大的网络补偿。

这里的“保留规则候选”只是保障表达能力；它不保证学习策略会选它，更不保证最终收益不低于规则。没有实际执行整条规则路线，就不能宣称享有其成本上界。现有 Fixed3 上界来自已保存并复验的锚点。

### 2.2 三种价值不是同一个标签

设状态 s 包含当前路线、最好路线、剩余步骤和工作量、完整动作尝试历史，h 为剩余决策次数。固定继续策略 π 的价值是

\[
Q_h^{\pi}(s,a)=\mathbb E_{\pi}\!\left[\sum_{k=0}^{\tau-1}r_{t+k}\mid s_t=s,a_t=a,h\right].
\]

G2.2 保存的是两个不同冻结策略各自的已选动作实际后缀。在本次确定性设置中，它是对应状态—动作—继续策略的实现值；不是对全部动作的标签。

原深度 2 教师标签则对已查询分支取有限最大值：

\[
Q_{T,d}(s,a)=r(s,a)+\max_{b\in E_T(s')}Q_{T,d-1}(s',b).
\]

这里的查询集合 E_T、深度 d、截断结算、预算与继续策略都必须明确。它不等于被冻结 CE 或 CE+收益继续得到的 Q^π，也不是完整动作空间和完整剩余预算上的 Q*。不能把两种标签混在一列回归，不能把未查询动作补成 0 或负值，也不能用 actor 分类 logit 与 STOP 的差替代经过标定的回报。

### 2.3 工作奖励与部署速度不是同一指标

当前完整回报为

\[
R_W=100(J_0-J_{\rm ret})/J_0-W/10^6,\qquad J=L+0.75K.
\]

工作计数中菜单占主要部分；墙钟中几何准备与 Fixed3 锚点占主要部分，二者权重没有天然对应。仅优化 R_W 不能证明完整规划更快。共享 STOP 的中位时间 452.49 ms，原 Fixed3 是 324.03 ms，说明零提案仍有显著适配器开销。CE+收益的主要问题也不能归结为纯网络前向耗时。

保留 R_W 可用于同接口的学习机制对照，但部署评估必须单独比较完整 J—时间关系。图构造、模型、菜单、验证都纳入完整时间；规则用同样的合法缓存和必要验证优化。不能只给学习模型换更有利的预算单位，也不能把重复校验清理带来的工程收益称为 RL 收益。规划计算时间与真实机器人作业时间同样需要分开。

## 3. 一个最小、可验证的改动方向

### 3.1 控制对象

每一步只有一个明确问题：**继续执行原 Detour 的下一操作、偏离到另一个合法局部操作，还是停止并返回最好路线？**

重用现有图编码器、可达性、局部修复和独立验证；加入规则下一动作作为显式候选。规则动作和学习替代动作走同一转移、相同成本结算。最强规则在这个接口中必须是可复现的策略，而不是只在外部报告一个难以比较的终局成绩。

保持可发生短时变差的当前路线与单调保留的最好路线分离。只允许单调接受会删除 G0/G1 所研究的一类机制；G2.2 没有证明该机制已被学习模型成功利用。h、剩余工作、尝试历史必须进入模型；没有这些信息，相同路线可能对应不同最优停止选择。

### 3.2 模型输出与停止

用独立数值价值头替换“把 CE 分类间隔作为收益”的做法。令 q_stop(s) 为在同状态立即停止的已知剩余记账值；在现有零势函数、已认证最好路线且无最终回退的条件下，它是尚未结算菜单费用的负值，**通常不是 0**。

模型估计

\[
\Delta_{\theta,h}(s,a)=Q_h^{\pi}(s,a)-q_{\rm stop}(s),
\qquad \Delta_{\theta,h}(s,\mathrm{STOP})=0.
\]

由同一组数值比较选动作和停止：继续动作的最大预测停止优势为正时选择其最大者，否则停止。若终验存在回退风险，必须将同一终验转移与质量修正纳入价值训练，不可沿用“STOP 无回退”的解析标签作无条件保证。

独立 head 的含义是价值输出有自己的数值监督和目标语义；它仍可共享图编码器，不意味着共享参数不存在耦合。部署阈值不能在测试集上为取得优势反复调整。

### 3.3 真正的多步 RL 增量来自哪里

优先使用**规则引导的近似策略迭代**这一条价值学习路线，不再把扩大 PPO 步数作为默认后续。

先用可复现的规则策略 π_D 形成初始化，明确每个标签的剩余 h、预算和继续策略。之后每个迭代 k 冻结被评价的继续策略 π_k，用真实转移训练价值，再更新策略。一个有明确语义的一步时序目标是

\[
y_t=r_t+\mathbf1_{\neg\mathrm{terminal}}
\sum_{b\in\mathcal A(s_{t+1})}\pi_k(b\mid s_{t+1},h-1)
\bar Q_{h-1}^{\pi_k}(s_{t+1},b)-q_{\rm stop}(s_t).
\]

回归 \(\Delta_{\theta,h}(s_t,a_t)\) 到该目标，或使用对应完整有限时域实际回报。有限时域采用 γ=1，避免不明折扣改变原有质量—工作目标。下一轮策略按预测 Q 改善，再采集它真正到达的新状态。探索混合“规则动作、当前策略、合法替代动作”，确保不是只有 STOP 和少数被旧教师覆盖的动作拥有数据；所有新分支和探索修复均计入同一个封顶预算。

若采用未来动作最大值目标，必须明确那已经改为估计有限预算的 Q*，而非 Q^π；若直接混用旧深度 2 最大标签与当前策略后缀，仍然重现原语义问题。对未访问动作的网络预测始终是泛化估计，保留规则动作不消除外推误差。

这条路线的 DRL 证据必须是“从实际环境反馈进行多步价值更新，策略改变后在独立任务上产生额外收益”。仅训练一次完整分支标签的回归网络仍应报告为监督价值学习；换上 Q 的符号不会自动成为强化学习创新。

## 4. 一次试验必须回答什么

建议下一轮作为一个不可自动扩大的完整研究试验，先冻结所有预算、数据划分和判定，再执行；本轮不启动它。

1. **可表达性闸。** 同接口复现强规则，确认规则每步都在菜单中。不能复现时不开始神经网络训练。
2. **单轮训练闸。** 从同一规则初始化出发，只研究上述一种多步价值更新。预先封顶新增修复调用总数，并把规则探索、补标签、在线学习全部计入；不能只限制“训练动作”而把大量教师查询排除。可将总新增非 STOP 修复上限建议定为 8,192 次，分配到 3 个训练种子；这是资源止损建议，不是足够收敛的理论保证，也不是本轮授权。
3. **机制与实用性一起验收。** 同接口强规则、相同数据与编码器的一步净价值模型、未进行多步更新的初始化模型，是必要的匹配比较；保留原 Fixed3/Detour16 作为外部部署参照。真正未用于开发的场景负责结论，旧 12 场景只作机制展示。时间重复测量，场景配对，训练种子分开报告，不把相关轨迹动作当作独立样本。若实际只能完成两步监督改善，照实称为有限深度监督搜索。

核心判据是：在预先固定的完整时间预算或非劣时间容差下，多步模型相对最强同接口规则以及一步学习对照，取得超过预定最小实用量的 J 改善，并通过代理可行性验证；同时报告配对不确定性与种子稳定性。若只有 R_W 改善、完整 J—时间没有更好，就不能声称“更快地生成更好路径”。最小实用量与容差必须在新测试结果出现前确定，不能用现有 12 场景倒推有利门槛。

## 5. 只有一条撤退条件

**规则动作覆盖与同接口复现完成后，这唯一一次封顶试验若仍不能在独立场景中取得对强规则和一步学习两者的实用增量，就停止把“Fixed3 初解上的局部窗口选择＋停止”作为第三部分 DRL 主创新，不再追加这个方向的训练轮数、网络规模或收益损失变体。**

这是一条研究资源决策，不是数学上证明所有更长时域或更多训练都无效。如果论文仍必须以 DRL 为核心，随后应重新立项到“服务停靠点选择、双臂任务分组与访问顺序的联合构造”，让模型拥有改变全局解结构的控制权；重用约束接口和验证器，但重新建立对应强基线与训练证据。构造式路线不是当前研究的快速小补丁，本轮不能承诺其结果，也不应与当前局部改进试验同时铺开。

当前最诚实而有研究价值的主张是：已经定位到部分有价值的未查询动作与停止代价错配，证明需要统一动作可表达性、数值价值语义和完整部署成本；**尚未得到能承担第三部分核心有效性结论的 DRL 模型**。
