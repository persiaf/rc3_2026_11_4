# G2：预算感知局部图 PPO 单种子小试


**完成了准备补丁、实际训练、同初始化对照、逐场景评测和模型导出。** 在固定工作预算评测中，最终 PPO 在 24／24 个验证场景根节点 STOP，返回成本与 Fixed3 相同。本轮没有得到优于强规则的学习规划器，不支持直接扩大到三种子或 65,536 步。


## 1. 本轮交付与范围


本轮是二维静态任务＋代理可达性的受控开发实验。正式网络为 65,602 参数的两轮稀疏局部图 actor–critic，从经验证的 Fixed3 初解开始，选择覆盖修复、扰动或 STOP；它不直接生成整条底盘折线。默认规划方法仍为原 Fixed3／Detour。v4、v5、v5.1 和 G01 保持冻结；真实标定、IK、动态任务和跨规模实验不在本轮范围。


公开工作借鉴及实际采用边界见 [OPEN_SOURCE_NOTES.md](OPEN_SOURCE_NOTES.md)：PPO-Clip／GAE、CleanRL 的采集契约、NeuOpt／RL4CO 的多步改进视角，以及 MPNN 的关系编码。当前是本地新写实现，未直接复现这些项目的整套模型或成绩。


## 2. 实际训练预算


| 项目 | 实际值 |
| --- | --- |
| 初始教师 | 64 场景／512 状态／4096 查询 |
| 追加教师 | 32 场景／256 状态／2048 查询 |
| 初始 BC | 400 更新，28.33 s |
| 继续 BC | 2048 额外更新，146.73 s |
| 正式 PPO | 32,768 已提交动作／128 rollout／2039 已提交优化更新 |
| PPO 已记录墙钟 | 2364.91 s（含固定检查点验证 46.48 s，不含中断间隔／未知尾段） |
| 完整 episode 记录 | 31,735；最终未结束 worker 状态单独保存在 checkpoint |
| 设备 | CPU；单模型线程，8 个单线程 NumPy/SciPy 环境 worker |
| 训练与验证 | 384 个新百桌训练场景池反复采样；24 个互斥新百桌验证场景（3 种模式各 8） |


训练场景是预登记的有限 384 场景池，不能称作每个回合都使用从未出现的新场景。两个 1,024 动作管线检查合计 2,048 个调试动作不计入正式 32,768。中断的教师 v1 已知 2,496 查询及无法完全核定的尾部工作另存，未用于正式初始化。教师求解、监督优化、环境交互和参数更新分别记账；同更新次数不等于同计算预算。


**中断与恢复口径：** 本轮进程在 18,432 步后随会话中断退出，之后从同源、同协议且与日志一致的检查点恢复。最终 32,768 指这条恢复链上已保存并用于正式更新的 on-policy 动作。中断时可能另有 0～256 个未落盘动作，以及最多一轮未提交的优化尝试；这些尾段的精确工作量和时间未知，不能将全部历史物理调用声称为恰好 32,768。训练器 elapsed_s 为已记录分段运行时间，不含中断间隔和未知尾段；详细证据见 `outputs/interruption_receipt.json` 与独立审计。


BC 与 PPO 从同一初始权重分叉。教师采用含工作费和终止事件的有限深度剩余回报，只在已查询 evidence mask 内监督；未知动作不作为负样本，有限深度标签不用于监督 horizon=16 的 critic。PPO 固定 gamma=1、GAE λ=0.95、clip=0.2、Adam 1e−4、4 epoch、minibatch64，全部超参数、数据种子和最终 32,768 检查点在查看验证前固定。

训练 episode 的 `complete_s` 包含等待采集器／优化器／阶段验证的墙钟时间，禁止用于部署耗时比较。训练准备缓存只复用不可变问题；所有最终比较都使用 fresh adapter。


## 7. 正确性、复核和负结果边界


最终 3 组比较共有 672 条运行记录，另有 3×24 个阶段检查点记录。这些重复方法／检查点仍只对应 24 个独立验证场景。最终保存方案的离线账本与摘要核对、实际重放样本、checkpoint 恢复和回归测试需分开计数，详见 `G2_AUDIT.md` 与 `outputs/g2_audit.json`。


本轮实际执行当前 G2 回归 71／71 项通过；独立审阅实际重放 6 份预登记方案，并对同一个保存 worker 做两次独立恢复，各采样 1 个真实动作后自然终止，结果一致。全部保存记录的离线复算不冒称全部重新执行。


状态恢复拒绝 NaN/Inf、非法计数及路线／菜单不一致并保持原子性；外部终止事件恰好一次并入最后真实动作，零动作仅记指标；采集长度截断继续保留环境；共享尝试记忆在菜单截断前屏蔽确定性无变化／失败动作并补位；重复路线认证可缓存，最终方案仍独立验证。已有 F∩A 共同约束继续通过原适配层使用。


若出现几乎全 STOP，它可降低搜索工作，却不证明学会了高质量多步决策。训练教师的部分有限树存在更好分支，因此需要把奖励下的探索、监督拟合与跨场景泛化分开诊断。本轮没有匹配的单调 PPO 消融，不能归因非单调机制；没有多架构正式训练，不能断言图网络普遍无效。

## 8. 使用与后续判断


最终研究权重为 `outputs/deployment/policy_ppo.pt`，另附冻结与继续 BC 的轻量参数包。它们保留研究和复现价值；生产默认入口保持原 Fixed3／Detour。运行说明见 [README_G2.md](README_G2.md)。图表脚本、PDF／SVG／PNG 与输入哈希位于 `figures/`。


本轮不自动追加 65,536 步或三种子。若后续继续，应先在独立开发场景检查教师动作排序、未知动作概率和STOP／继续搜索的回报差，再预登记新的探索或监督方案；不能用当前验证集反复改奖励后继续当作未见数据。最终独立的主张判定与下一步路由见结果审阅文件。
