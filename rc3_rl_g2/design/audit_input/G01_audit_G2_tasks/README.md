# G0/G1 复核与 G2 实施任务包

日期：2026年11月3日。

本包是对用户交付 rc3_rl_research_g01.zip 的复核材料及下一阶段编程任务书。它不包含新训练器、神经网络权重或新的性能评测结果。

## 阶段判断

G0/G1 足以支持进入 G2 准备和一个种子的受控小试。研究主线建议明确为“可达性约束下，预算感知的多步动作选择与停止决策”。非单调探索保留为可选能力与待验证消融，不能把使用变差动作的比例当作成功指标。

主要证据均来自同一批 32 个开发场景、每节点已查前 7 个非 STOP 动作、深度 3 的有限树。这里的“最优”只指已查询的树内。

本轮没有重新执行整棵 G0 树，也没有重新执行全部 32 条轨迹；对全部原始日志做了离线复算，并对两条代表性轨迹实际重放。原报告的 32/32 完整重放属于交付者的历史记录。

## 单命令复算日志统计

需要原 G0/G1 包及 NumPy。无需 PyTorch，也不调用修复求解器，不训练或重新规划。

~~~bash
python audit/audit_records.py \
  --source /absolute/path/to/rc3_rl_research \
  --output /absolute/path/to/new_audit_output
~~~

请指向包含 outputs/g0 的原研究模块目录，不是压缩包文件。输出到一个新目录。脚本生成四个 JSON 和一份 CSV；根目录 stdout 仅给摘要。

环境故障注入 JSON 使用很小的合成夹具，用来说明状态恢复和终止事件接口风险，不属于新增机器人实验。
