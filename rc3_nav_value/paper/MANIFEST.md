# R0 研究证据目录

- `../r0_run.py`：一次性登记、校准、教师执行与保存验证。
- `../r0_analyze.py`：保存记录统计、资源、CSV与报告复算，无规划调用。
- `../REPORT_R0.md`、`../README.md`、`../findings.md`、`../EXPERIMENT_RESULT_TO_CLAIM.md`：结果及结论边界。
- `../r0/protocol.json`、`seeds.json`、`seed_audit*.json`、`seed_audit_inventory.jsonl`、`seed_audit_tool.py`：协议和查重溯源。
- `../r0/registration_attempt1/`、`registration_amendment.json`：只读预检中规范摘要与字节摘要误比的原始登记及修正。
- `../r0/wall_protocol.json`、`calibration_started.json`、`run_started.json`、`execution_summary.json`：先冻结后执行的链条。
- `../r0/calls.jsonl`、`evaluations.jsonl`、`checkpoints.jsonl`：实际终局调用、标签与候选选择。
- `../r0/scenes/`、`baselines/`、`plans/`：32固定场景、B与根参照、96方案。
- `../r0/case_results.json`、`analysis.json`、`per_scene.csv`、`resources.json`、`verification.json`：数值总表、主门槛和资源核验。
- `review-traces/experiment-result-to-claim/2026-11-05_run01/`：独立审查，未执行额外研究调用。
- `../r0/STATUS.json`、`frozen_integrity.json`：R0完成及后续未启动状态，旧项目字节核验。
- 全项目字节清单继续由 `project_management/GIT_MANIFEST.json`统一记录，无新增整包ZIP。
