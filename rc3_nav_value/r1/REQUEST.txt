承接上面的判断：R0 已经证明问题中存在可以利用的长期决策机会，但还没有证明神经网络能够学会这些机会，更没有证明深度强化学习优于强规则。

我认为现在应当正式把研究推进到 R1：融合覆盖与导航关系的长期价值学习，以及有限策略迭代验证。相比过去反复调整 PPO、奖励和训练次数，这次有了一个更明确的研究起点：先用 R0 的真实补全结果确定什么是有价值的动作，再研究模型能否在不执行大量在线补全的情况下作出相近决策。

## 二、R1 应该建立什么模型

建议模型名称暂定为：

覆盖—导航关系增强的长期价值规划网络（Coverage–Navigation Relational Value Network，CNR-VN）

它的核心功能不是直接预测一个任务点应该由哪只机械臂执行，而是预测：

> 如果下一步选择某个服务停靠点，最终完成全部剩余任务并经过统一后处理后，路线总代价预计是多少？

### 1. 将 R0 教师作为价值监督来源

保持原来的完整后处理 \\(H\\) 不变。对于状态 \\(s_t\\)、当前路线前缀 \\(P_t\\) 和候选动作 \\(a\\)，定义：

\\[ Y^{g_k}(s_t,a) = J\left( H\left[ P_t\oplus a\oplus \operatorname{Complete}\_{g_k}(s_t,a) \right] \right). \\]

其中 \\(g_k\\) 是固定版本的参考补全策略。

进一步定义相对参考动作 \\(a\_{\mathrm{ref}}\\) 的优势：

\\[ \Delta^{g_k}(s_t,a) = \frac{ Y^{g_k}(s_t,a\_{\mathrm{ref}}) - Y^{g_k}(s_t,a) }{ \max(Y^{g_k}(s_t,a\_{\mathrm{ref}}),\varepsilon) }. \\]

这里正值表示候选动作比参考动作更好。

网络学习：

\\[ \widehat{\Delta}\_\theta(s_t,a) \approx \Delta^{g_k}(s_t,a). \\]

部署时只需要网络计算候选价值，不必对所有候选重新运行完整补全。

建议对实际查询过的动作使用数值回归与排序损失联合训练，避免重复 G2.1 中“已查询动作标签拟合良好，但完整菜单排序不可靠”的问题。没有查询过的动作继续保持未知，不能填成零收益或负样本。

### 2. 网络结构建议

建议的 R1 模型结构示意。覆盖关系、导航关系和前缀信息分别编码后融合，不改变原有合法动作与独立验证逻辑。

其中三个分支有不同职责。

覆盖分支判断候选站点能够处理哪些任务、覆盖是否重叠，以及哪些任务缺少替代服务位置。

导航分支不只读取当前位置到候选的距离，还引入候选之间的真实绕障距离 \\(D\_{jk}\\)，帮助预测后续路线连接代价。

前缀分支保留已经构造的服务顺序。因为后处理可能删除、替换和重排已选停靠点，仅靠当前位置和剩余任务不能充分表达最终成本。

对于百桌约 800 个候选的规模，不建议每一步都重新运行完整稠密注意力。可以先采用 64 维、两层编码器，在固定稀疏导航邻域上聚合，静态图特征缓存，动态覆盖和前缀信息逐步更新。稀疏化的是信息传播关系，不是擅自删除合法服务动作。

这里要保留一项研究边界：R0 证明了有价值的动作选择机会，没有证明新增 \\(D\_{jk}\\) 是必要信息。严格的导航信息缺口见证仍属于另一个尚未通过的 G1—G4 问题。R1 可以检验导航表示是否改善有限网络的学习效果，但不能提前宣称已经证明其信息必要性。

## 三、R1 最关键的实验：把表示收益和强化学习收益分开

建议沿用已评审方案中的四组结构，而不是只训练一个新网络。

| 组别 | 输入表示          | 学习机制     | 主要用途   |
| -- | ------------- | -------- | ------ |
| A  | 覆盖与基础导航特征     | 固定参考价值监督 | 基础模型   |
| B  | 覆盖＋候选间导航关系＋前缀 | 固定参考价值监督 | 检验改进表示 |
| C  | 与 A 相同        | 两轮近似策略迭代 | 检验多步学习 |
| D  | 与 B 相同        | 两轮近似策略迭代 | 完整研究模型 |

最关键的是两个配对差：

\\[ \Delta\_{\mathrm{RL}} = J_B-J_D, \\]

\\[ \Delta\_{\mathrm{nav}} = J_C-J_D. \\]

两者分别回答：

- 使用同样表示时，闭环强化学习是否优于静态价值监督？
- 使用同样迭代机制时，增加导航关系是否有收益？

需要注意，B 与 D 的数据分布可能因为策略改进而不同，因此固定监督对照也应获得匹配的新增状态和查询预算，不能让 D 因为采到了更多有价值的新数据而天然占优。

此外，还必须比较 D 与共同起点、原第 128 次权重、纯先验、Fixed3 和 Detour16。仅 D 比 A 或 C 好，仍不足以证明它具有实际采用价值。

## 四、建议如何执行两轮策略迭代

这一部分与以前直接延长 REINFORCE 或 PPO 训练最不同。

1. 初始化价值网络。 使用与 R0 相同的完整终局成本语义建立教师标签，先确认已查询动作内的数值预测、排序和未知动作审计可以通过基本检查。
2. 第一次策略评价。 冻结参考策略 \\(g_0\\)，选择部分实际前缀，查询参考动作及预设替代动作的完整后处理成本，训练 \\(Q_0\\) 或相对优势网络。
3. 第一次策略改进。 通过新的价值网络形成 \\(g_1\\)。在新实例中真正按照 \\(g_1\\) 构造路线，而不只是对原教师旧状态进行重复分类。
4. 第二次策略评价与改进。 冻结 \\(g_1\\)，评价它真实到达的新前缀与后续成本，得到新的价值标签，再形成 \\(g_2\\)。所有标签保存所属策略版本。
5. 冻结完整模型并进行配对评价。 D 与 B、C、共同起点和强规则在相同场景、相同后处理、相同合法约束下输出完整方案；全部进行独立验证与耗时记录。

为什么一定要加入第二轮？

因为第一轮只是在拟合固定参考策略下的成本，即：

\\[ Q^{g_0}(s,a). \\]

这种监督模型即使有效，也可能只是“把搜索结果压缩进网络”。

当网络真正改变策略后，后续状态和补全行为也会变化。如果能够重新评价：

\\[ Q^{g_1}(s,a), \\]

并产生更好的 \\(g_2\\)，才形成更充分的近似策略迭代证据。

但完成两轮更新本身仍不能证明强化学习有效。最终必须由 D 相对静态监督 B 的独立收益支持。

## 五、R1 的预算和门槛不需要临时扩大

建议继续遵守评审修订版的 R1 有界预算，总终局评价上限为 16,384 次，包括教师初始化、配对策略评价和必要审计。

| 预算类别    | 建议上限     |
| ------- | -------- |
| 共享初始化标签 | 4,096 次  |
| 配对策略评价  | 8,192 次  |
| 验证与审计   | 4,096 次  |
| 合计      | 16,384 次 |

其中验证与审计额度内，建议按已修订方案预留 1,024 次模型实际选择的未查询动作核查。它们要计入总额度，不能算作免费的额外搜索。

R1 首先只做一个匹配训练种子的机制筛选。若 D 在预先指定的新开发集上取得明确改进，包括优于同结构静态监督、改善共同起点且完整时间有竞争力，再进入 R2 的三个独立训练种子确认。R1 出现正结果不等同于 R2 已通过。

我建议同时设置两项硬性研究纪律：全部合法方案必须通过代理验证；任何新增训练不得读取原来封存的 60 个测试场景。旧 R0 的 32 个场景可以作为开发与教师诊断证据，但不能重新包装成独立测试。

## 六、现在最需要警惕的三个问题

### 教师比参考规则好，并不表示模型容易学会

R0 使用了 2,144 次顶层评价，最终教师在全部 32 个场景获得改善。这是搜索能力。

神经网络可能因为状态表达不充分、训练样本稀疏、候选间差距很小、未知动作价值估计错误而无法复制教师。

因此，R1 要把“已查询动作内的拟合质量”和“完整合法菜单中的实际路径质量”分开汇报，避免重复 G2.1 的错误。

### 模型对未知动作的过度乐观可能再次造成退化

R0 每个检查点只查询最多 8 个合法候选，不是全动作枚举。模型未来会对更多动作作出价值预测。

如果它把没有见过的某个动作预测得异常好，完整构造质量可能迅速变差。

建议除均方误差外，专门记录网络实际选中动作的真实补全差距、未知动作选择比例和最差场景损失。遇到明显价值低估，应先处理表示与监督范围，不能简单通过加大训练更新数解决。

### 教师可能依赖过多在线计算

R0 的教师采用大量完整后处理和候选终局评价；它不是一个已完成的快速部署规划器。

因此，R1 成功不仅意味着接近教师成本，还要证明网络能够以较少的实际完整时间产生竞争性结果。

最终至少展示：

\\[ (J,\ T\_{\mathrm{median}},\ T\_{\mathrm{p95}},\ \text{可行率}) \\]

而不是只展示训练损失或平均奖励。

## 七、这对第三部分硕士论文意味着什么

现在可以逐步形成一条更清晰的创新证据链：

| 研究层次              | 当前状态          | 未来需要证明的内容       |
| ----------------- | ------------- | --------------- |
| 可达约束下的多任务路径规划     | 已有完整求解与代理验证系统 | 保留为前两部分的建模与求解基础 |
| 长期动作评价存在改进空间      | R0 已通过        | 已取得有界教师证据       |
| 融合覆盖与导航关系能够改善价值判断 | 待 R1 验证       | B 对 A、D 对 C     |
| 近似策略迭代产生独立学习增量    | 待 R1／R2 验证    | D 对 B，以及相对共同起点  |
| 强规则前沿上的实用收益       | 尚未证明          | 质量、完整时间和可行率共同达标 |
| 不同桌数与任务分布下的泛化     | 尚未证明          | R3 冻结模型后的跨规模测试  |

我建议继续将第三部分定位为：

“面向移动双臂操作任务的覆盖—导航关系增强与长期价值强化学习路径规划方法”。

但在 R1、R2 完成之前，论文里的“融合关系表示提高决策质量”和“强化学习能够加快规划”都应写为研究目标，不能提前作为已经验证的创新成果。

## 八、下一步交给 Codex 的实施范围

建议下一轮只建立一个独立的 `rc3_nav_value/r1/` 研究模块，保持 R0 输出、旧第 128 次权重和 Fixed3／Detour 不变。

首先完成完整前缀状态、真实终局价值标签和两种表示的训练接口；然后实现四组配对对照、两轮策略迭代、未知动作审计、完整验证及资源账。所有输出包含协议、模型权重、训练记录、逐场景成本、完整时间、配对区间和失败原因。

最关键的验收问题只有一个：在相同计算与数据条件下，D 是否真正比 B 更好，并且改善共同起点，而不只是比一个退化更多的对照好。

如果成立，就进入 R2 三种子独立确认；如果不成立，结束该配置，保留 R0 已证实的教师搜索价值及 R1 的具体限制，不再无依据地追加训练。

目前最值得肯定的进展，是研究终于从“反复尝试训练一个模型”转向了“先验证长期决策机会，再针对这些机会建立可归因的学习机制”。R0 已完成第一步；R1 应当检验第二步。
