# R1：CNR-VN 单种子有界筛选与收尾

**本配置未通过 R1 继续门槛，结束追加训练，不进入 R2/R3。** 首轮两种表示的候选改善区间均跨零，参考策略没有晋升。两轮终点均保持 A=C、B=D 的参数张量及完整路线一致，D 对 B 的改善为 0，95% 区间 [0,0]。因此本轮没有形成有效参考更新的近似策略迭代证据，不能据此断言 API 一般无效。

D 的路线质量仍低于共同暖起点以外的旧权重与强规则，完整时间也没有部署优势。默认 Fixed3／Detour 不变。R0 的有界教师机会证据保留；原 G1—G4 未执行、未通过，原 60 个保留测试继续封存。

## 实际执行与归因边界

独立目录 `r1/`，基线提交 `129ba6e916ed5a44ecb92998553c082b4510ecd1`，分支 `main`。先登记协议与源码/种子/H 哈希，再生成场景与标签；协议 SHA256 为 `f2384fe7b661c41e19d596fe0a4db018a8b86a6d74471cb884354d6a669772c3`。

四组使用同样的 64 维、2 层结构、完整前缀 GRU 和 75,393 个参数。共同输入包含覆盖、真实当前/回家 D、前缀边成本及精确合法动作；候选图拓扑均为纯几何 16 近邻加 4 个远邻。A/C 的候选关系值是欧氏距离，B/D 是真实导航 D。稀疏图只限制消息聚合，全合法菜单保持开放。

按照用户新任务，在注册前将旧 J-only Huber 方案改为相对优势 Delta 的查询动作回归加排序联合损失。未查询动作没有零标签或负标签。暖启动仅用 gB 标签；每轮只用该轮冻结参考策略的标签，不混合不同参考目标。A/B 是**固定 g0 参考、获得匹配状态和查询的价值监督对照**，不是静态旧数据集。C/D 为预留参考晋升路径的闭环候选。

训练为 32 张新地图各一个任务实例，开发为另 32 张新地图各一个任务实例，均按 regular/mixed/blocked=11/11/10。单训练种子 11412026；重复菜单、批次或审计不是额外独立场景。开发集同时用于参考晋升与最终筛选，所有区间仅是探索性开发证据。

## 价值学习与未知动作诊断

不能把本轮解释为“已查询拟合已很好，只剩未知动作”。D2 在当轮128个已见训练状态上的查询动作优势 MSE 为 0.000953，查询对符号准确率59.87%，查询菜单 top1 命中率22.66%，平均查询 top1 优势遗憾2.5308个百分点。查询集合内排序本身仍较弱。

D2 在128个审计状态中124次选择查询菜单外动作，未知选择率96.875%。这些未知选择相对 g0 的平均真实优势仍为 +0.1176%，所以“未知”不等于必坏；但相对该状态的已查询最优动作，平均有符号差距为3.3717% Yref，正遗憾为3.6392%，最差差距12.4449%。未知选择的平均预测乐观偏差为1.3350个百分点，乐观符号错误率46.77%。

四组两轮共1024个审计机会、920次未知选择，其中大量为配对和跨轮重复，不是1024个独立实例。只对实际选中的未知动作补全，精确缓存后新增431次终局调用；没有另挑未知动作，也没有把审计标签反馈训练或晋升。诊断针对已见训练前缀上的动作外推，不能声称未见状态泛化已验证。

这些结果支持“本配置的查询排序及全菜单外推尚不足以产生可靠终局策略”，未独立定位为容量、输入表示、优化或标签稀疏中的某一个原因。不能据此直接追加更新次数。
